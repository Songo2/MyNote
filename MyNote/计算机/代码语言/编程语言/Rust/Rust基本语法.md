# 变量
## 可变性
在Rust中声明变量使用`let`关键字
```Rust
let num = 5;
```
在默认情况下,变量是不可变的(immutable),绑定之后再绑定将在编译时报错
加上`mut`关键字将变为可变的变量
```Rust
let mut num = 5;
```
Rust是强类型语言,但是具有类型推断的功能,在声明变量时可以根据绑定确定变量类型
___
## 常量
虽然Rust中存在"不可变"的类似常量的一种语法,但是Rust中仍然存在常量,.使用`const`关键字声明常量
```rust
const MAX: u32 = 100000;
```
常量和不可变的变量的差异
- 不可以再使用mut恢复可变性
- 必须标注类型
- 可以在任何作用域内声明,包括全局
- 只可以绑定到常量表达式,无法绑定到函数的调用结果或只能在运行时才能计算出的值
在程序运行时,常量在其声明的作用域内一直有效
___
## 隐藏
Shadowing,当需要改变不可变变量的值时,在Rust直接修改会报错
```rust
let x = 5;
let x = x + 1;
```
像上面的代码,把第二行的let去掉后会报错
加上let之后相当于重新声明了x,但后面表达式中的x仍是原来的值,这时候发生了隐藏,原有的值被隐藏起来,当新的值被绑定后原有值将丢弃
这样修改值的方式和mut后直接修改的不一样
- mut不允许修改数据类型
- mut不允许可变性
