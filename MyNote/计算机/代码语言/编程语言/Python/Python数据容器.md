Python中的数据容器一共有5种,分别为字符串str(ing),列表list,元组tuple,集合set,字典dict(ionary)

对于空的数据容器,它们对于的布尔值都是False

# 字符串
字符串是一种专门针对字符的容器,Python其实和其他的语言不同,不区分字符串和字符
## 格式

字符串可以用单引号`''`,双引号`""`包裹起来,但是这样的字符串是单行的,输入时不允许换行,需要用转义字符`\n`实现输出时换行
```python
A="Hello,Python"
B="这是一句话/n这是第二句话"
```
在程序中单引号和双引号最好只使用一种

空字符串直接用一对引号表示

如果需要可换行的字符串,也就是块字符串,需要使用三引号`'''`
```python
P='''
这是一段话
我可以自由换行
'''
```
同时三引号也可以用来做注释

## 有序性
字符串是一个序列,它是有序的,可以通过索引访问和切片
```python
A="Hello,world"
a=A[3]
h=A[0:4]
```

## 只读性
字符串在创建之后不允许直接修改它的元素
但可以让变量指向另外一个字符串
```python
A="change?"
# A[-1]="d"
A="changed"
```

## 可迭代性
字符串是一个可迭代对象
```python
A="Python"
for i in A:
	print(i)
```

# 列表
列表是常用的一种数据容器,有序且可修改,由于Python的弱类型特点,列表不限制元素的数据类型

## 格式
列表使用方括号`[]`来包裹元素
```python
A=[] # 创建空列表
```

## 多元性
列表里可以有多种数据类型的元素
```python
A=[1,3.14,"Python"]
```

## 有序性
列表也是一个序列,可以使用索引访问和切片,切片后产生的是一个子列表
```python
A=[1,2.71,3.14,4,5]
a=A[2]
b=A[1:3]
```

## 可写性
列表是可以修改元素的
```python
A=[1,2,9,4,5]
A[2]=3
```
