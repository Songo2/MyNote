# Python在设计上简洁优雅
[[Python之禅]]
其语法和关键字设计接近英语本身,所见即所得.

优先保障开发效率而不是运行效率,你的时间比机器的时间更宝贵.

一切皆为对象,Python为弱类型语言,无需强调数据类型,动态类型,一个变量承接一切.


# 其优势在于:
社区生态庞大,拥有大量第三方库,解决问题不再闭门造车.

其简单自然的语法易于上手,学习成本低,学习难度小.

项目实现简单,开发周期短.

同时易于粘合其他语言,成为胶水语言.


# 其缺点是:
作为解释型语言,运行速度慢于C/C++等语言.

无法作为底层或者满足高性能应用开发.

动态类型容易造成维护的隐患,过于简单和自由的语法导致检查错误比较困难.

多线程受限制无法真正并行.
