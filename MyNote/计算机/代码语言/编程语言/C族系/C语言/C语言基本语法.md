# 数据类型
作为一门较老且基础的编程语言,C语言并没有特别多的数据类型
## 基本数据类型
### 空类型 void

### 字符型 char
这个类型只能存储单个字符,占一个字节的空间,实际存储的是这个字符的编码

### 值类型

#### 整型
最常用int,也包括short,long,long long
int通常占四字节,short两字节,long long固定八字节,long是四或八字节,跟系统有关

#### 浮点型
教学常见float,日常常用double,此外还有long double
float四个字节,double八个字节,long double十六个字节

#### 无符号型
以上介绍的值类型都是默认为有符号的,即为signed类型,占用了一个二进制位做符号位的,在类型前面加unsigned会变成无符号的对应类型,占用空间不变

## 派生数据类型
### 数组类型(array)
将某一特定类型的多个单独数据封装在一起,它是有序的,可以通过下标访问其中的数据

### 指针类型(pointer)
记录某一特定数据类型的一个数据的地址,可以通过取地址&获取目标的地址,也可以用解引用\*获取指针指向的目标

### 结构体(structure)
将几个不同类型的数据结合在一起,整体作为一个数据对象,可以通过访问其成员来获取被结构体结合在一起的数据

### 联合体(Union)
利用同一个空间,储存多种不同类型的数据,不同数据类型作为其成员,通过访问其成员来切换当前使用的数据类型

### 枚举(enumeration)
存储的数据可能性有限,一个可能数据对应一个名字,这个名字本质是一个整数常量的名字,枚举的本质是一个整数类型

# 语句结构

## 顺序结构
从上到下按顺序一条条执行代码语句的结构,是普通的结构

## 选择结构

### if-else体系
#### 单分支if
```c
if(条件)
选项语句
```
当程序执行到这个结构的时候,先执行if()语句,对条件进行判断,如果条件语句的值为真,则执行选项语句,为假则不执行,继续向下执行,其中选项语句是一条语句,可以用块语句拓展
```c
if(条件)
{
	选项语句1
	选项语句2
	......
}
```

#### 双分支if-else
```c
if(条件)
真选项
else
假选项
```
与单分支不同,当条件为假时,将执行else后面的假选项语句

#### 嵌套多分支 if-else if-else...
```c
if(条件)
{
	if(真条件)
	{
		真真语句
	}
	else
	{
		真假语句
	}
}
else
{
	if(假条件)
	{
		假真语句
	}
	else
	{
		假假语句
	}
}
```
在选项语句中我们还可以加入if-else结构进行嵌套,产生多分支结构,程序会层层判断条件执行语句

### switch体系
```c
switch(判断依据)
{
	case A:
		语句1
		break;
	case B:
		语句2
		break;
	......
	default:
		默认语句
		break;
}
```
当程序执行到这个结构时,会根据判断依据的情况,如果是A,则从case A的语句开始执行程序,如果是B,则是从case B的语句开始执行......如果没有符合的情况,则执行default后面的语句,当程序执行到break时则退出此结构

## 循环结构

### for体系
```c
for(初始语句;条件语句;迭代语句)
循环体语句
```
当程序执行到这个结构时,先执行初始语句,然后进入循环,循环按条件--循环体--迭代语句进行,当条件语句为真时循环就会进行

### while体系
```c
while(条件)
循环体语句
```
和for不同,while只有条件和循环体,如果满足条件则执行循环体,直至不符合条件

### do-while体系
```c
do
{
	循环体语句
}
while(条件语句);
```
和while不同,这个结构会先执行一次循环体再进行判断

### 跳转语句

#### break语句
在循环体中如果执行到break语句,那将会直接跳出循环往下执行,结束本层循环

#### continue语句
在循环体中如果执行到continue语句,会从当前的循环体中跳出来,重新判断条件,也就是结束本次循环

## goto结构

### 标签语句
```c
标签:语句;
```
在语句前加上一个标签标识,作为goto语句跳转的目标语句

### goto语句
```c
goto 标签;
```
当程序执行到这个结构时,将从标签所指的语句开始执行,标签应该和goto在同一个函数里

# 声明和定义
## 声明
```c
类型 变量名;
```
表明代码实体类型,名字等必要内容的语句是声明

## 定义
对于代码实体的详细内容进行说明的语句是定义,声明必须先于定义,必须先声明才能使用
# 函数

函数是一段代码片段,它可以被多次调用,我们的入口main()就是一个函数

## 声明和定义
```c
返回值类型 函数名(参数列表)
{
	函数体
}
```
函数体之前的部分是函数的声明,也叫做函数头,加上函数体即为定义

## 调用
```c
函数名(传入的参数);
```
调用函数后将把传入的参数当作对应函数定义中的参数从而执行这段代码片段,并返回规定类型的数据

## 返回
```c
返回值类型 函数名(参数列表)
{
	函数体
	return 返回值;
}
```
返回的内容由return语句决定
