
chemarr,即chemistry arrow,化学箭头,在表示化学反应的时候常需要一个可逆箭头,这个包提供了这个箭头

```
\xrightleftharpoons[\text{below}]{\text{above}}
```

$$
A \xrightleftharpoons[\text{below}]{\text{above}} B
$$

类似的有amsmath的
```
\xrightarrow[\text{below}]{\text{above}}
```

$$
A \xrightarrow[\text{below}]{\text{above}} B
$$

```
\xleftarrow[\text{below}]{\text{above}}
```

$$
A \xleftarrow[\text{below}]{\text{above}} B
$$
