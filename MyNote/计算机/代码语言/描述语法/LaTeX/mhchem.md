
# 命令

命令的核心是`\ce{}`
```
\ce{}
```

## 化学式

表示化学式在符号后面直接打数字就是下标(),兼容LaTeX的`_{}`下标

```
\ce{H2O}
```
$$
\ce{H2O}
$$
```
\ce{Sb2O3}
```
$$
\ce{Sb2O3}
$$
___
空格会分隔化学式
```
\ce{N2O2}
```
$$
\ce{N2O2}
$$
```
\ce{N2 O2}
```
$$
\ce{N2 O2}
$$
___
### 电荷

如果是单个正负电荷,直接在化学式对应位置打上`+/-`就行
```
\ce{H+}
```
$$
\ce{H+}
$$
```
\ce{OH-}
```
$$
\ce{OH-}
$$
___
如果是多个电荷,则需要使用LaTeX的上标`^{}`,而表示正负的`+/-`可以放进去`{}`也可以不放进去,多个数字可以放进`{}`,也可以不带`{}`
```
\ce{Y^99+}
```
$$
\ce{Y^99+}
$$
```
\ce{Y^{99}+}
```
$$
\ce{Y^{99}+}
$$
```
\ce{Y^{99+}}
```
$$
\ce{Y^{99+}}
$$
___
同时这部分和下标不冲突
```
\ce{CrO4^2-}
```
$$
\ce{CrO4^2-}
$$
___
配离子直接使用方括号就行
```
\ce{[AgCl2]-}
```
$$
\ce{[AgCl2]-}
$$
___
### 氧化态

直接使用上标`^`来表示氧化态
```
\ce{Fe^{II}Fe^{III}2O4}
```
$$
\ce{Fe^{II}Fe^{III}2O4}
$$
___
### 化学计量数

化学计量数的表示是在化学式前加数字,可以带空格
```
\ce{2H2O}
```
$$
\ce{2H2O}
$$
```
\ce{2 H2O}
```
$$
\ce{2 H2O}
$$
___
支持小数
```
\ce{0.5H2O}
```
$$
\ce{0.5H2O}
$$
___
也支持分数,不需要`\frac{}{}`就能表示出分数线,但加括号会保留`/`
```
\ce{1/2H2O}
```
$$
\ce{1/2H2O}
$$
```
\ce{(1/2)H2O}
```
$$
\ce{(1/2)H2O}
$$
___
可在其中嵌入数学公式
```
\ce{$n$H2O}
```
$$
\ce{$n$H2O}
$$
___
### 核素或同位素

使用一个占位的`{}`(可不打)的上标`^`和下标`_`来表示质量数和质子数
```
\ce{^227_90Th+}
```
$$
\ce{^227_90Th+}
$$
```
\ce{{}^{227}_{90}Th+}
```
$$
\ce{{}^{227}_{90}Th+}
$$
```
\ce{^0_-1n-}
```
$$
\ce{^0_-1n-}
$$
```
\ce{^{0}_{-1}n^{-}}
```
$$
\ce{^{0}_{-1}n^{-}}
$$
___
如果上下标存在归属歧义,可以使用`{}`来划分
```
\ce{H^3HO}
```
$$
\ce{H^3HO}
$$
(这里的上标在第一个H上)
```
\ce{H{}^3HO}
```
$$
\ce{H{}^3HO}
$$
(这里的上标在第二个H上,或者说中间的占位符上)
___
### 括号

圆括号`()`
方括号`[]`
花括号`\{ \}`

```
\ce{(NH4)2S}
```
$$
\ce{(NH4)2S}
$$
```
\ce{ [ \{ ( X2 )3 \}2 ]^3+ }
```
$$
\ce{ [ \{ ( X2 )3 \}2 ]^3+ }
$$
___
同样有`\left`和`\right`构成的大括号环境,如果本身不在`$$`环境里则需要另外嵌入
```
\ce{CH4 + 2\left( O2 + 79/21 N2 \right)}
```
$$
\ce{CH4 + 2\left(O2 + 79/21 N2\right)}
$$
```
\ce{CH4 + 2 $\left( \ce{O2 + 79/21 N2} \right)$}
```
$$
\ce{CH4 + 2 $\left( \ce{O2 + 79/21 N2} \right)$}
$$
___
### 物质状态

直接使用括号即可
```
\ce{H2(aq)}
```
$$
\ce{H2(aq)}
$$
```
\ce{NaOH(aq,\infty)}
```
$$
\ce{NaOH(aq,\infty)}
$$
___
### 未配对电子和自由基

对应的电子用小数点`.`即可
```
\ce{OCO^{.-}}
```
$$
\ce{OCO^{.-}}
$$
```
\ce{NO^{(2.)-}}
```
$$
\ce{NO^{(2.)-}}
$$
___
### 配合物

中间的原点可以用`./*`表示,空格对其不会有影响
```
\ce{KCr(SO4)2*12H2O}
```
$$
\ce{KCr(SO4)2*12H2O}
$$
```
\ce{KCr(SO4)2.12H2O}
```
$$
\ce{KCr(SO4)2.12H2O}
$$
```
\ce{KCr(SO4)2 * 12H2O}
```
$$
\ce{KCr(SO4)2 * 12H2O}
$$
___
### 化学键

单键`-`
```
\ce{C6H5-CHO}
```
$$
\ce{C6H5-CHO}
$$
mhchem会尝试区分减号,连字符和单键
___
双键` =`
```
\ce{CH2=CH2}
```
$$
\ce{CH2=CH2}
$$
需要和等于号区分开来
___
三键`#`
```
\ce{CH#CH}
```
$$
\ce{CH#CH}
$$
___
bond命令
使用
```
\bond{}
```
可以表示化学键,`{}`中输入键数即可,对于三键,输入`-/=/#`也可以

```
\ce{A-B=C#D}
```
$$
\ce{A-B=C#D}
$$
```
\ce{A\bond{1}B\bond{2}C\bond{3}D}
```
$$
\ce{A\bond{1}B\bond{2}C\bond{3}D}
$$
```
\ce{A\bond{-}B\bond{=}C\bond{#}D}
```
$$
\ce{A\bond{-}B\bond{=}C\bond{#}D}
$$
___
配位键`\bond{->}/\bond{<-}`

```
\ce{A\bond{->}B\bond{<-}C}
```
$$
\ce{A\bond{->}B\bond{<-}C}
$$
___
过渡键/共振结构(离域$\pi$键)/反馈$\pi$键

在`\bond{}`里使用`~`,可以组合

```
\ce{A\bond{~}B\bond{~-}C}
```
$$
\ce{A\bond{~}B\bond{~-}C}
$$
```
\ce{A\bond{~--}B\bond{~=}C\bond{-~-}D}
```
$$
\ce{A\bond{~--}B\bond{~=}C\bond{-~-}D}
$$
___
氢键

在`\bond{}`里使用`.`,可以有三个或四个

```
\ce{A\bond{...}B\bond{....}C}
```
$$
\ce{A\bond{...}B\bond{....}C}
$$
___

### 反应条件

反应条件写在箭头上,参数如下
```
A arrow[above][below] B
```

```
\ce{Hg^2+->[I-] HgI2->[I-] [Hg^{II}I4]^2-}
```
$$
\ce{Hg^2+->[I-] HgI2->[I-] [Hg^{II}I4]^2-}
$$

```
$$
\ce{A + B}

\ce{A - B}
```
$$
\ce{A - B}
$$
```
\ce{A \pm B}
```

\ce{A \pm B}

___
### 沉淀与气体

沉淀符号为`v`,气体符号为`^`,防止歧义可以加括号`(v)/(^)`

```
\ce{SO4^2- + Ba^2+ -> BaSO4 v}
```
$$
\ce{SO4^2- + Ba^2+ -> BaSO4 v}
$$
```
\ce{A v B (v) -> B ^ B (^)}
```
$$
\ce{A v B (v) -> B ^ B (^)}
$$
