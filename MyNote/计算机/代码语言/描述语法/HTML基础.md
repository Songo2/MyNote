#HTML #前端 #Web开发
HTML,全称超文本标记语言(HyperText Markup Language),是用来构建网页的标准语言,是一种标记语言,通过一系列标签告诉浏览器如何显示内容

# 基础语法

## 入口
```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>页面标题</title>
</head>
<body>
    <!-- 所有用户能看到的内容，都写在这里 -->
</body>
</html>
```

### \<!DOCTYPE html>
这是文档说明,表明这个文档是最新的HTML5页面

### \<html>
这是根标签,所有内容都写在里面,其中lang="zh-CN"是指明页面语言是中文

### \<head>
网页头,放置网页的配置信息,不直接显示给用户,如其中的\<meta charset="UTF-8">指明网页的编码方式是UTF-8,\<title>显示网页标题

### \<body>
网页体,内部写网页的可见内容

## 标签
HTML 就是用一对对尖括号包裹的“标签”来标记内容,另外标签名不区分大小写,由标签和其内容组成的就是HTML的元素

### 双标签
这是最常见的一种标签形式,由开始标签,内容,结束标签表示,结束标签要加斜杆
```html
<标签名>内容</标签名>
```

```html
<p>这是一个段落</p>
```

### 单标签(自闭合标签)
这种标签不包裹内容,直接在开始标签处结束
```html
<标签名/>
<!--或者-->
<标签名>
```

例如
```html
<br>
<!--换行-->
<hr>
<!--水平线-->
<img src="..." alt="...">
<!--插入图片-->
<input type="text">
<!--输入框-->
```

### 注释标签
HTML里注释也是通过标签来写的
```html
<!--注释-->
```
由感叹号和双横线(减号)组成,注释写在中间

### 标签嵌套
标签包裹的内容里的内容里可以再有标签,这是标签的嵌套,但HTML的标签嵌套要求正常包裹而不允许交叉:先开始的后结束
```html
<外标签>
	<内标签>
	"..."
	</内标签>
</外标签>
```

## 属性
我们可以给元素添加属性,属性写在开始标签里,以属性名="属性值"的方式写入,同一个属性不能在一个标签里出现多个
```html
<标签名 属性名="属性值">内容</标签名>
```
同样,属性名也不区分大小写,但是一般用全小写

### 布尔属性
有部分属性的值只有真假,真值就是属性名,假值则是完全不写值,或者根本不写这个属性
```html
<!--真-->
<标签名 布尔属性名="布尔属性名">内容</标签名>
<!--假-->
<标签名 布尔属性名>内容</标签名>
```

### 自定义属性
在HTML中允许自定义数据,格式为data-自定义属性名="属性值",自定义属性也可以从HTML传递到JavaScript,自定义属性名post-id在JavaScript中会转换成小驼峰命名法的postId
```html
<标签名 data-自定义属性名="属性值">
	内容
</标签名>
```

# 元素详解

## 标题
h标签是标题的标题,h1是一级标签,h2是第二级标签......h6是最小级别的标题

## 文本修饰标签

### 格式

#### 超链接(锚点)
使用\<a>标签,渲染为蓝色并加下划线

#### 缩写
使用\<abbr>标签,渲染出虚线下划线,鼠标悬停会有title的提示

#### 作品标题
使用\<cite>标签,渲染为斜体

#### 行内代码片段
使用\<code>标签,渲染为等宽字体

#### 机器数据
使用\<data>标签,是普通文字,一般配合value使用

#### 定义术语
使用\<dfn>标签,渲染为斜体,或者单纯普通文字,一般配合title使用

#### 东亚文字注音
使用\<rp>/\<rt>/\<ruby>标签,渲染为小字上标或者标注

#### 程序输出示例
使用\<samp>标签,渲染为等宽字体

#### 日期
使用\<time>标签,是普通字体,配合datetime使用

#### 变量名
使用\<var>标签,渲染为斜体

#### 键盘输入
使用\<kbd>标签,渲染出等宽文字和灰色背景

### 样式

#### 隔离文本方向
使用\<bdi>标签

#### 覆盖文本方向
使用\<bdo>标签,配合其中dir属性

#### 换行
使用\<br>标签

#### 删除线
使用\<del>标签

#### 强调
使用\<em>标签,是斜体

#### 斜体
使用\<i>标签

#### 插入
使用\<ins>标签,是下划线

#### 高亮标记
使用\<mark>标签,会渲染黄色背景

#### 短引用
使用\<q>标签,会渲染引号

#### 不确定文本
使用\<s>标签,渲染出删除线

#### 通用无语义容器
使用\<span>标签,无样式,是CSS的钩子

#### 强紧急性文字
使用\<strong>标签,会加粗

#### 小字
使用\<small>标签

#### 上标
使用\<sup>标签

#### 下标
使用\<sub>标签

#### 下划线
使用\<u>标签

#### 建议换行点
使用\<wbr>,不可见,仅影响断行

## 列表

### 无序列表
Unordered List
使用\<ul>标签,其中的内容使用\<li>标签(List Item),展示出的内容是无序的
```html
<ul>
  <li>苹果</li>
  <li>香蕉</li>
  <li>橙子</li>
</ul>
```

### 有序列表
Ordered List
使用\<ol>标签,其中的内容也使用\<li>标签,和ul不同,这个列表展示处理的内容是有序的
```html
<ol>
  <li>起床</li>
  <li>刷牙</li>
  <li>吃早餐</li>
</ol>
```

其中\<ol>标签有三个特别的属性
start 指定起始数字,默认为1
reversed 是否倒序,最后一个数字变为1
type 编号类型 改成"A",会变成A,B,C
在\<li>标签上有value属性,可以手动修改编号

### 描述列表
Description List
使用\<dl>标签,其中的内容分两部分,一部分是描述项,另一部分是具体描述,分别使用\<dt>和\<dd>标签
```html
<dl>
  <dt>HTML</dt>
  <dd>超文本标记语言，构建网页结构。</dd>

  <dt>CSS</dt>
  <dd>层叠样式表，负责表现和布局。</dd>

  <dt>JavaScript</dt>
  <dd>脚本语言，实现动态交互。</dd>
</dl>
```

dt和dd都不强制对应,可以多对多

### 嵌套列表
ul或者ol也可以包裹进li里,但是ul的直接子元素只能是li
```html
<ul>
  <li>水果
    <ul>
      <li>苹果</li>
      <li>香蕉</li>
    </ul>
  </li>
  <li>蔬菜
    <ul>
      <li>菠菜</li>
      <li>胡萝卜</li>
    </ul>
  </li>
</ul>
```

# 布局设计

## 盒模型
在HTML里,所有元素都是装在一个不可视的矩形盒子里,盒子的每一层数据可以被CSS控制
### margin
外边距,与其他盒子的距离,即和其他元素之间的距离

### border
边框,盒子的可见边框

### padding
内边距,边框与内容之间的填充

### content
控制内容数据

## 布局等级
### 块级

块级元素默认独占一整行,宽度撑满父容器,可以设置宽高例如\<p>等标签

### 行级元素

行级元素在一行内排列,宽度由内容决定,不能设置宽高如\<strong>等标签

### 规则

块级元素可以包裹行级元素,但行级元素不能包裹块级元素


## 语义分区
HTML5提供了一整套用来描述页面结构的标签,它们天然具有布局意义(块级元素),能把页面分成清晰的区域,给页面画出清晰的分区,非常利于 SEO,无障碍和后期 CSS 美化

### \<header>
页面或文章头部的容器

### \<nav>
导航链接区域

### \<main>
页面独有的主要内容,每个页面只用一个

### \<section>
按主题分组的区块,通常带有自己的标题

### \<article>
独立的内容块,如一篇博客,一条评论

### \<aside>
与主体相关但不核心的内容,如侧边栏,广告

### \<footer>
页面或文章底部信息

## 内容流控制
这些是 HTML 里最基础的“排版”元素,直接控制文本和内容的流动

### \<p>
段落,默认上下有间距,将文字分成块,是文本布局的基础

### \<br>
强制换行,在行内制造断裂,类似“软回车”

### \<hr>
水平分隔线,表示主题转换,视觉上画一条横线

### \<wbr>
可换行点(浏览器在必要时才换行),控制长单词或URL的断行位置

### \<pre>
保留空格和换行符,等宽字体,展示代码或格式文本
