
# 介绍

## 描述
Markdown 是一种轻量级标记语言,让你用纯文本就能写出格式丰富的文档.它由 John Gruber 在 2004 年创建,核心目标是“易读易写”

## 功能
用简单的符号(如 `#`、`*`、`-`)标记文本结构,就能转换成排版好的 HTML,PDF 等格式.它广泛用于写博客,README 文档,笔记,论坛帖子等

## 优点
纯文本，随处可用:任何编辑器都能打开,不依赖特定软件
语法简单，专注于内容:几乎不影响阅读，没有复杂菜单
可轻松转成 HTML：非常适合网页内容创作

# 语法

## 基础语法(标准Markdown)

### 标题
Markdown用井号`#`来表示标题层次,第几级标题用几个井号,最多到六级

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

可以用七个横线闭合标题
```markdown
# 一级标题
二级标题
--------
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

### 文本强调
用成对的星号或`*`下划线`_`可以强调文字,需要包裹起来,一对是斜体,两对是粗体,三对是粗斜体
```markdown
*斜体*  或  _斜体_
**粗体**  或  __粗体__
***粗斜体***  或  ___粗斜体___
```

### 列表

#### 无序列表
用单独的星号`*`,横线(减号)`-`或加号`+`可以创建无序列表,此时嵌套需要两空格缩进
```
- 项目一
- 项目二
  - 嵌套项目（前面缩进两个空格）
```

#### 有序列表
用数字加英语句号可以创建有序列表,此时嵌套需要三空格缩进
```
1. 第一项
2. 第二项
   3. 嵌套子项（缩进三个空格）
```

### 链接

#### 行内式b
在行内显示链接用中括号`[]`表示文字,用括号`()`表示网页地址
```markdown
[文字](http://example.com)
```

#### 参考式
把行内式的括号加地址的部分改为中括号加参考id,再用`[id]`:地址的方式解释
```markdown
[文字][id]
[id]: http://example.com
```

### 图片
和链接类似,在前面加感叹号`!`
```markdown
![文字](图片地址)

![文字][id]
[id]:图片地址
```

### 引用块
使用大于号`>`创建引用块,嵌套再加一个`>`
```markdown
> 这是一层引用
> > 这是嵌套引用
```

### 代码
使用点号\`创建代码,单对是行内代码,三对是代码块,代码块在开始的三点后要加编程语言名

```markdown
`print("hello world")`
```

### 分隔线
在一行中使用不小于三个的星号`*`,下划线`_`或者横线`-`
```markdown
---
```

### 段落和换行
两个空格加换行是换行
空一行是新段落

### 转义字符
反斜杠\可取消特殊字符的效果

## 拓展语法

### 任务列表
用横线和中括号`- []`,括号里面不填是未完成,填x是已完成
```markdown
- [ ] 未完成
- [x] 已完成
```

### 表格
用竖线`|`创建表格,两竖线中间的就是一个格子
可以在格子的下一行规定它的对齐方式,`:---`是左对齐,`:---:`是居中对齐,`---:`是右对齐
```markdown
| 左对齐 | 居中对齐 | 右对齐 |
| :--- | :---: | ---: |
| 内容 | 内容 | 内容 |
```

| 左对齐 | 居中对齐 | 右对齐 |
| :--- | :---: | ---: |
| 内容 | 内容 | 内容 |

### 删除线
用波浪线`~`来创建删除线,两对波浪线包裹着文字
```markdown
~~删除文字~~
```

~~删除文字~~

### 脚注
用方括号和脱字符`[^]`创建脚注,脚注还需要解释即`[^]:`
```markdown
这里需要脚注[^1]
[^1]: 脚注内容写在这里
```

这里需要脚注[^1]
[^1]: 脚注内容写在这里

### 自动链接
用尖括号`<>`包裹起来的地址可以直接点击
```markdown
<http://example.com>
```

<http://example.com>

# AI应用

## 结构化
AI 模型（如 GPT-4、Claude）在训练时“读”过海量的 Markdown 文档，因此它非常擅长解析这种格式。当你用 Markdown 写指令时，等于在给模型一个清晰的思维框架
```markdown
# 角色
你是一个客服助手

## 核心规则
- 语气要友好
- 不知道就说“不知道”

### 禁忌
- 绝对不要承诺任何赔偿
```

模型能明确识别：`# 角色` 是顶层定义，`## 核心规则` 是子任务，列表是具体条目。这就**极大地减少了歧义**，比一大段纯文本指令的效果稳定得多

## 混合内容
AI 的提示词中往往既要写自然语言指令，又要包含代码示例、示例对话、输出模板等。Markdown 的代码块（用三个反引号）可以安全地嵌入多语言代码，且不会和指令本身混淆

## 元数据与正文天然分离
很多 SKILL / Agent 文件头部会使用 YAML Front Matter：
```markdown
---
name: web-search
description: 搜索网络的技能
version: 1.0
---
# 技能指令
当用户想搜索时...
```

程序可以快速读取 `---` 之间的参数（名称、版本、依赖）来做任务调度，而下面的 Markdown 正文供模型阅读理解。机器可读的配置与人类可读的逻辑完美共存

## 生态工具
AI 开发的四大环节中，每个环节的主流工具都原生支持 Markdown：

- **工程框架**：LangChain、LlamaIndex 使用 Markdown 加载文档、切割语料。
    
- **Agent 平台**：CrewAI 用 Markdown/YAML 定义 Agent 角色；AutoGPT 用 Markdown 存储长期记忆。
    
- **RAG 知识库**：绝大多数企业文档都先转成 Markdown 再入库。
    
- **提示词管理**：提示词版本管理工具（如 promptfoo）直接 diff 你的 `.md` 文件，格式清晰。

## 版本控制与协作
因为 Markdown 是纯文本，Git 能清晰地展示每次修改了哪一行，谁改了什么。对比 Word 或二进制文件，这更适合做精细化的提示词迭代和 AB 测试

## 输出可直接面向用户
很多 AI 的输出就是 Markdown 格式（比如 ChatGPT 的返回），因为它能快速转换为 HTML、PDF 等。用一套格式完成“输入定义 - 模型理解 - 结果输出”的全流程，极大降低了转换成本
