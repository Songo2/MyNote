# 介绍
Shell是一种专门用于与操作系统交互的脚本语言,它也是个命令解释器
和Python类似,它也有交互式和脚本式,在交互式命令行界面输入一条指令,Shell就立即解释并执行

## 起源
初代Shell是sh,全称是Bourne Shell,由 Steve Bourne 在贝尔实验室开发,所有 Unix/Linux 系统的基石，是 POSIX 标准的基础.几乎每个现代系统上 `/bin/sh` 都是一个指向某个兼容 Shell 的链接
现在主流的还有Bash,Linux 和 macOS 的默认 Shell，兼容 sh，并加入命令补全、历史、数组等大量增强功能
另外还有微软开发的PowerShell,但是PowerShell的一般Shell不同,PowerShell借鉴了现代编程思想，把一切视为对象 (Objects)

## 本质
Shell是用来指挥操作系统核心(Kernel)即内核的工具,作为包在内核外面的界面,它就叫Shell(壳)

Shell的底层是C语言,使用Shell指令本质上是在调用系统的C语言程序

## 特点
### 解释型
无需编译,直接由 Shell 解释器逐行读取执行

### 弱类型
一切皆字符串,变量默认都是字符串,没有整数,浮点数的严格类型区分

### 强大的管道与重定向
`|` 和 `>` 是 Shell 的灵魂,可以把小工具串联成复杂的数据处理流

### 命令即代码
几乎所有系统命令都能直接写进脚本,脚本本质上就是命令的编排

### 胶水语言
非常适合把不同语言写的程序(Python,C,awk,sed 等)粘合在一起。

### 高度依赖环境
不同系统、不同 Shell 版本，行为可能差异较大。

## 优点
### 无缝操控系统
进程管理,文件操作,定时任务,系统监控,Shell 是天然的控制器

### 极速原型开发
几行代码就能完成复杂的系统自动化任务

### 无处不在
所有类 Unix 系统(Linux,macOS,BSD)都内置，几乎不需要额外安装

### 管道思维强大
将简单工具组合，产生 1+1>2 的效果

## 缺点
### 语法怪异且不严谨
空格,引号,括号容易出错,隐蔽的陷阱多
 
### 数据结构简陋
主要处理字符串和简单数组，复杂数据结构难实现。
 
### 性能有限
不适合计算密集型任务，每次调用外部命令都创建子进程。

### 可移植性问题
bash 脚本未必能在 sh 下运行，不同系统命令的选项可能略有差异。

### 调试相对困难
虽然有 `set -x` 等工具，但处理大型项目时光靠 Shell 会显得吃力。

## 哲学

### 文本
一切皆为文本

### 小即是美
每个工具只干一件事

### 让程序相互配合
用管道,重链接组合能力

# 交互

## 显示提示符
进入命令行交互界面,Shell会输出一段提示符
```shell
用户名@账号:-$
```
等待用户输入,其中`$`表示普通用户,`#`表示root用户

## 读取命令
用户输入命令后,按下回车,Shell就会读取输入的命令

## 解析命令
Shell会拆解输入的这一行文本,将其拆分为命令和参数,并处理其中的特殊字符,这个过程称为展开

## 查找并运行
Shell根据拿到的命令文本去判断其是内置命令,外部程序文件还是别名,然后创建一个子进程去运行它

## 返回结果与状态
命令执行完后,Shell获取其退出状态码(0表示成功,非0表示失败,保存在`$?`变量里),并显示输出,然后重新输出显示提示符

# 脚本

```shell
#!/bin/bash
```

### 授权
```shell

```

### 指定
```shell
bash script.sh
```

# 基本语法

## 变量

### 定义变量
命名满足[[[编程语言标识符基本规则]]],由于Shell是弱类型语言,所以不需要声明类型,但和普通编程语言不同,在赋值时等号两边不允许有空格
```shell
name="Alice"
age=25
```

### 使用变量
Shell中皆是字符串,所以使用变量一般是输出,此时需要在变量前加`$`,也可以用花括号把变量括起来表示变量名的范围
```shell
echo "My name is $name"
echo "I am ${age} years old"
```

### 只读变量(常量)
在变量前加`readonly`则会变成只读变量,无法修改,无法删除

### 删除变量
使用`unset`可以删除变量
```shell
unset age
```

### 数值变量
虽然变量里都是字符串,但是数值不用加引号,而且可以进行计算
```shell
num=10
echo $((num + 5))
```

### 特殊变量
|变量|含义|
|---|---|
|`$0`|脚本自身的名字|
|`$1`~`$9`|传入脚本的第1到第9个参数|
|`$#`|参数个数|
|`$@`|所有参数列表（每个参数字段独立）|
|`$*`|所有参数合并成一个字符串|
|`$?`|上一条命令的退出状态（0 表示成功）|
|`$$`|当前 Shell 的进程 ID|

## 字符串

### 引号
可以用单引号`''`或者双引号`""`来包裹字符串,但是两者有区别,单引号内的字符串所有字符保持原样,双引号内的字符会解析变量和转义符

### 拼接
在字符串内加入带`$`的变量可以让对应的字符串拼接在对应位置
```shell
str="Hello, World"
name="Songo"
greeting="$str, I'm $name"
```

### 取长度
在字符串前面加`#`会取其长度
```shell
str="Hello, World"
echo ${#str}
```

### 取子串
在字符串后面加`:a:b`可以根据索引取子串
```shell
str="Hello, World"
echo ${str:0:5}
```

### 查找替换
在字符串后面加`/`可以查找后替换
单个只替换第一个,两个是全体替换
```shell
str="Hello, World"
echo ${str/o/O}   # 将第一个小写 o 替换为大写 O
echo ${str//o/O}  # 将所有小写 o 替换为大写 O
```

## 数组
这个语法在sh里没有,Bash里有

### 定义数组
使用小括号包括元素,元素之间用逗号分隔
```shell
fruits=("apple" "banana" "orange")
```

### 访问元素
使用中括号来通过索引访问元素
```shell
fruits=("apple" "banana" "orange")
echo ${fruits[0]}  # apple
echo ${fruits[2]}  # orange
```

### 获取长度
获取长度还是用`#`,但是需要索引,索引为数字时获取的是对应字符串的长度,但是索引为`@`时则获取到数组长度,也就是字符串个数
```shell
fruits=("apple" "banana" "orange")
echo ${#fruits[@]}   # 元素个数
echo ${#fruits[1]}   # 第二个元素的长度
```

## 运算

### 数值计算
Shell本身不擅长数值计算,通常需要使用命令
旧式sh使用`expr`命令

#### expr
运算符与操作数之间**必须有空格**，否则会被当作一个字符串。
表达式结果不为空或不为 0 时返回 0（成功），若语法错误或结果为 0/空则返回 1
##### 整数算术计算
expr只支持整数运算
支持加`+`,减`-`,乘`*`,除`/`,取余`%`
其中由于`*`有特殊意义,所以需要加上转义符
```shell
expr 5 + 3        # 8
expr 10 - 2       # 8
expr 4 \* 3       # 12
expr 9 / 2        # 4（只取整数部分）
expr 9 % 2        # 1
```

##### 比较运算
支持 =（等于）、`!=`（不等于）、`>`（大于）、`>=`、`<`、`<=`。  
比较结果：条件成立输出 `1`，不成立输出 `0`。
```shell
expr 5 = 5        # 1
expr 5 != 4       # 1
expr 3 \> 5       # 0（大于号需转义）
expr 3 '>' 5      # 也可用引号
```

##### 逻辑运算
`|`（或）、`&`（与）
两个运算符都需要转义
非零即为真,但是expr也能处理字符串,所以字符串非空即为真
```shell
expr 0 \| 3       # 3（0为假，返回右边的3）
expr 5 \& 0       # 0（需两边非0才返回第一个值）
expr 5 \& 6       # 5
```

##### 字符串操作
###### 求长度
`expr length "hello"` → 5
 
###### 子串
`expr substr "hello" 2 3` → `ell`（起始索引从 1 计）

###### 索引
`expr index "hello" "el"` → 2（返回字符集中任意字符首次出现的位置）

###### 模式匹配/提取
`expr match "hello123" "[a-z]\+"` → 5（匹配并返回匹配长度）  
或使用 `:` 运算符：`expr "hello123" : "[a-z]\+"` → 5  
提取部分：`expr "hello123" : ".*\([0-9]\+\)"` → `123`（使用 `\(\)` 捕获）
#### 现代`$(())`
```shell
$((算术表达式))
```
$(())是对expr的现代替换
Shell会先计算表达式,然后把整个$(())替换为结果
$(())支持大多数C语言的整数运算符
在$(())里面引用变量不用再加\$,如果引用了未定义的变量则视为0
```shell
# 算术运算
sum=$(( 5 + 3 ))          # sum=8
diff=$(( 10 - 2 ))        # diff=8
product=$(( 4 * 3 ))      # product=12（无需转义乘号）
quotient=$(( 9 / 2 ))     # quotient=4（整数除法，向下取整）
remainder=$(( 9 % 2 ))    # remainder=1

# 自增自减（类似 C 语言，但注意：$((i++)) 会先返回值再自增，需结合变量赋值）
i=5
echo $(( i++ ))           # 输出5，然后 i 变成6
echo $(( ++i ))           # 输出7（先自增再取值）

# 复合赋值（需要配合 let 或整体赋值给变量）
(( i += 2 ))              # 等价于 i=$(( i+2 ))，i 变为9
(( i *= 2 ))              # i 变为18

# 比较与逻辑（结果 1 为真，0 为假）
result=$(( 10 > 5 ))      # result=1
result=$(( (5>3) && (2<1) )) # result=0

# 三元运算
max=$(( a > b ? a : b ))

# 进制支持（前缀 0 表示八进制，0x 表示十六进制）
echo $(( 012 ))           # 10（八进制 12 = 十进制 10）
echo $(( 0xFF ))          # 255

# 在条件语句中（不需要 $ 符号，使用 ((...)) 作为命令）
if (( a > b )); then
    echo "a is greater"
fi
```
其中赋值运算存在副作用

#### (())
(())等价于`let`,和$(())类似,但是(())不输出内容,只有退出码
```shell
(( 5 > 3 ))
echo $?    # 输出 0（表达式为真）
(( 5 > 8 ))
echo $?    # 输出 1（表达式为假）

# 若表达式结果恰好为 0，则退出码为 1（假）
(( 0 ))
echo $?    # 1
(( -1 ))   # -1 非零，退出码 0
```


### 关系测试
条件测试旧sh使用text或其别名\[]来简写,现代Shell里使用\[\[]]

#### text 简写为\[]
```shell
[ 条件表达式 ]
# 等价于
test 条件表达式
```
命令执行后，返回退出状态码,0为假,1为空值
一般要求变量还要用双引号包裹,防止出现空值导致错误


##### 数值比较
| 操作符   | 含义                | 示例 (`[]`)       |
| ----- | ----------------- | --------------- |
| `-eq` | 相等 (equal)        | `[ $a -eq $b ]` |
| `-ne` | 不等 (not equal)    | `[ $a -ne $b ]` |
| `-gt` | 大于 (greater than) | `[ $a -gt $b ]` |
| `-lt` | 小于 (less than)    | `[ $a -lt $b ]` |
| `-ge` | 大于等于              | `[ $a -ge $b ]` |
| `-le` | 小于等于              | `[ $a -le $b ]` |

##### 字符串测试
| 操作符  | 含义         | 示例                   |
| ---- | ---------- | -------------------- |
| `=`  | 字符串相等      | `[ "$s1" = "$s2" ]`  |
| `!=` | 字符串不等      | `[ "$s1" != "$s2" ]` |
| `-z` | 字符串长度为零（空） | `[ -z "$s" ]`        |
| `-n` | 字符串长度非零    | `[ -n "$s" ]`        |
`<` 和 `>` 在 `[ ]` 中需要转义，且按字典序比较（与 locale 相关）

##### 文件测试
操作符	含义
-e	文件或目录存在
-f	存在且为普通文件（不是目录或设备文件）
-d	存在且为目录
-s	存在且大小非零（不是空文件）
-h / -L	存在且为符号链接
-b	存在且为块设备文件
-c	存在且为字符设备文件
-p	存在且为命名管道（FIFO）
-S	存在且为套接字（socket）
-r	存在且当前用户可读
-w	存在且当前用户可写
-x	存在且当前用户可执行（目录为可搜索）
-u	存在且设置了 SUID 位
-g	存在且设置了 SGID 位
-k	存在且设置了 Sticky 位
-O	存在且当前用户是文件所有者
-G	存在且当前用户属于文件所属组
-N	存在且自从上次读取后被修改过
file1 -nt file2	file1 比 file2 新（修改时间）
file1 -ot file2	file1 比 file2 旧
file1 -ef file2	两个文件指向同一个 inode（硬链接或相同文件）

##### 布尔与逻辑运算
与：-a 或 &&
```shell
[ $a -gt 1 -a $b -lt 10 ]
# 或者
[ $a -gt 1 ] && [ $b -lt 10 ]
```

或：-o 或 ||
```shell
[ $a -eq 1 -o $b -eq 3 ]
# 或者
[ $a -eq 1 ] || [ $b -eq 3 ]
```

非：!
```shell
[ ! -f "/etc/passwd" ]
```

#### \[\[]]
`[[ ]]` 的核心特性

##### 字符串比较
\==和!=支持正则表达式模式匹配,右侧可包含通配符 `*`、`?`、`[ ]`
=等价与==
不需要对变量加双引号,即使变量内容为空或含空格，也能正确处理

##### 正则表达式匹配
使用=~
右侧是一个扩展正则表达式（ERE）
匹配成功返回 0（真）
匹配的部分可以通过 `BASH_REMATCH` 数组访问
```bash
text="abc123"
if [[ $text =~ ^[a-z]+[0-9]+$ ]]; then
    echo "matched"
    echo "whole: ${BASH_REMATCH[0]}"   # abc123
fi
```

##### 逻辑运算符
支持分组 `( )`（无需转义）
```bash
age=25
if [[ $age -gt 18 && $age -lt 60 ]]; then
    echo "adult worker"
fi
```

##### 数值比较
\[\[ 5 > 3 ]]会按字符串比较（因为 > 在 \[\[ ]] 中也是数值比较？实际上 \[\[ ]]内部 > 和 < 当两边是数字时仍然执行数值比较，但建议明确使用 -gt 以免混淆）
```shell
x=10
y=20
if [[ x -lt y ]]; then
    echo "x < y"
fi
```

##### 不需要词分割或路径扩展
在 `[[ ]]` 中，变量扩展的结果不会进行词分割（Word Splitting）或路径扩展（Pathname Expansion），因此即使变量包含空格或 `*`，也是安全的。
```shell
file="my file with spaces.txt"
if [[ -f $file ]]; then    # 正确，无需引号，因为 [[ ]] 内部不分词
    echo "exists"
fi
```
