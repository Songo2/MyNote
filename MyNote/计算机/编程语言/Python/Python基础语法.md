# 数据类型

[[Python标准库]]
## 动态类型语言/弱类型语言
Python的变量不严格限制其数据类型,一个变量可以接受所有类型的数据[[Python设计哲学与思想]].

除了变量之外,函数的形参,函数的返回值也都没有限制其类型.

## 基本数据类型
虽然Python不严格限制变量的数据类型,但这并不意味着Python没有数据类型.为了方便进行数据之间的运算处理,Python也约定了一些数据类型并为其编写了若干方法.

### NoneType 空值/空类型

### int 整数/整型

### float 浮点数/实型

### complex 复数/复型

### str 字符串

### bool 布尔值/逻辑型

### set 集合

Python中使用print()函数进行输出除了输出的内容外,还有两个关键字参数,sep表示间隔符,end表示结尾字符
```Python
print("Hello", "world", sep=" ", end="!")
```
