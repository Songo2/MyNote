
塞缪尔定义机器学习是赋予计算机在没有明确编程的情况下学习能力的研究领域

>Machine Learning:"FIeld of study that gives computers the ability to learn without being explicity programmed"
>--Arthur Samuel(1959)

塞缪尔的成名之作是在20世纪50年代编写了一个跳棋程序,而这个跳棋程序的惊人之处在于,塞缪尔本身不是一个很好的跳棋玩家,他所做的是编写一个程序,让计算机可能与自己对弈数万局,通过观察哪些棋盘位置倾向于导致胜利,哪些位置倾向于导致失败,跳棋程序随着时间推移学会了什么是好的或坏的棋盘位置,通过尝试达到好的位置并避免坏的位置,这个程序学会了且越来越擅长玩跳棋,这就是机器学习

因为计算机有耐心与自己对弈数万局,它能够获得如此多的跳棋经验,最终比塞缪尔本人更擅长玩跳棋

不过,如果这个程序从原先的数万局对弈改为十来局对弈,情况会变得怎么样,一般来说它的表现会变差

一般来说,你给学习算法更多的学习机会,它的表现就会越好

# 监督学习

机器学习的两种主要类型是监督学习和无监督学习,其中监督学习是许多实际应用中最常用的机器学习类型,并且也是发展最快和创新最多的

监督学习指的是学习$X\to Y$或者说输入到输出映射的算法,监督学习的关键特征是,你给学习算法提供包含正确答案的示例,这里的正确答案指的是给定输入$X$的正确标签$Y$,通过看到正确的输入$X$和期望的输出标签$Y$,学习算法最终学会了在没有输出标签的情况下,仅凭输入就能给出相当准确的预测或猜测

|     Input(X)     |       output(Y)        |     Application     |
| :--------------: | :--------------------: | :-----------------: |
|      email       |       spam?(0/1)       |   spam filtering    |
|      audio       |    text transcripts    | speech recognition  |
|     English      |        Spanish         | machine translation |
|   ad,user info   |      click?(0/1)       | online advertising  |
| image,radar info | position of other cars |  self-driving car   |
|  image of phone  |      defect?(0/1)      |  visual inspection  |

在这些应用中,你首先会用输入$X$和正确答案(即标签$Y$)的示例来训练你的模型,在模型从这些输入输出或$X$和$Y$的数据对中学习之后,它可以接受一个全新的输入$X$(模型训练时未包含的),并尝试生成相应的适应输出$Y$

## 分类

还有第二种主要的监督学习问题,称为分类

以乳腺癌检测为例,假设你正在构建一个机器学习系统以便医生可用使用,这很重要,因为早期检测可能会挽救潜在的患者的生命,使用患者的医疗记录,你的机器学习系统试图判断一个肿瘤即肿块,是恶性或者危险的,还是良性的

例如我们有一个数据集,有各种大小的肿瘤,这些肿瘤有的被标记为良性的,我们用0表示,有点被标记为恶性的,用1表示,然后我们可以在图表上绘制数据,其中横轴表示肿瘤大小,纵轴只取两个值,0或1

| :--: | :-------: |
|  1   |     0     |
|  2   |     0     |
|  3   |     0     |
|  4   |     0     |
|  5   |     1     |
|  6   |     0     |
|  7   |     1     |
|  8   |     0     |
|  9   |     1     |
|  10  |     1     |
|  11  |     1     |

## 总结

监督学习将输入$X$映射到输出$Y$,其中学习算法从正确算法中学习,监督学习的两种主要类型是回归和分类,在回归应用中,学习算法必须从无限多的可能输出数字中预测数值,而在分类中,学习算法必须从一小部分可能的输出中预测一个类别
___

我们不被要求诊断肿瘤是良性还是恶性,因为我们没有在数据集中得到任何标签$Y$,相反,我们的工作是找到一些结构或者一些模式,或者在数据中发现某些东西,这就是无监督学习

我们称之为无监督是因为我们不是试图监督算法为每个输入提供某种正确的答案,相反,我们要求算法自己找出数据中可能有趣或存在的模式或结构

对于这个特定的数据集,无监督学习算法可能会决定数据可以分配到两个不同的组或者两个不同的簇中

这是一种称为聚类算法的无监督学习,因为它将无标记的数据放入不同的组中,这被证明在许多应用中使用

例如谷歌新闻,它每天会查看互联网上数十万条新闻文章,并将相关的故事分组在一起,新闻主题每天都在变化,有太多新闻故事,让人们在每天为所有新闻故事主题做这件事是不现实的

相反,算法必须在没有监督的情况下自己找出今天的新闻文章的组,这就是为什么这种聚类算法是一种无监督学习算法

无监督学习指的是数据只有输入$X$,但没有标签$Y$,算法需要从这些数据中找到某些结构,模式或有趣的东西

除了聚类算法,还有异常检测,用于检测异常事件,这在金融系统中的欺诈检测中非常重要,异常事件,异常交易可能是欺诈的迹象,并且在许多其他应用中也很有用

另外还有降维算法,这使你可以将大数据集几乎神奇地压缩为小得多的数据集,同时尽可能少地丢失信息
