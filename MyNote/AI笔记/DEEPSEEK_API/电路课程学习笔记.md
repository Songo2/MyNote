## 一、基本概念

### 1.1 电路与电路模型
- **电路**：由电气元件按一定方式连接，提供电流流通路径的网络。
- **电路模型**：用理想元件（如电阻、电容、电感、电源）近似实际元件的电磁特性，形成数学模型。
- **集总参数电路**：当电路尺寸远小于工作波长时，元件参数可集中处理，不随空间变化。

### 1.2 基本变量
- **电流**：电荷定向移动的速率，$i(t) = \frac{dq}{dt}$，单位：安培（A）。
- **电压**：单位正电荷从一点移到另一点所获得或失去的能量，$u(t) = \frac{dw}{dq}$，单位：伏特（V）。
- **电功率**：单位时间吸收或发出的能量，$p(t) = u(t) \cdot i(t)$，单位：瓦特（W）。
- **参考方向**：人为假定的电流、电压正方向，用于列写方程。计算结果为正值表示实际方向与参考方向一致；负值则相反。

### 1.3 基本元件约束关系
- **电阻**：线性电阻的电压与电流成正比，$u = R i$，电阻 $R$ 单位欧姆（$\Omega$）。电导 $G = 1/R$。
- **电容**：$i = C \frac{du}{dt}$，$u(t) = \frac{1}{C}\int_{-\infty}^{t} i(\tau)d\tau$。电容 $C$ 单位法拉（F）。
- **电感**：$u = L \frac{di}{dt}$，$i(t) = \frac{1}{L}\int_{-\infty}^{t} u(\tau)d\tau$。电感 $L$ 单位亨利（H）。
- **独立电压源**：端电压为给定值 $u_s(t)$，与流过电流无关。
- **独立电流源**：输出电流为给定值 $i_s(t)$，与其端电压无关。
- **受控源**：输出电压或电流受电路中另一处电压或电流控制，类型：电压控电压源（VCVS）、电压控电流源（VCCS）、电流控电压源（CCVS）、电流控电流源（CCCS）。

## 二、基本定律

### 2.1 基尔霍夫电流定律（KCL）
对于任一集总参数电路中的任一节点，流入该节点的电流代数和为零：$\sum i = 0$。
推广到闭合面也适用。

### 2.2 基尔霍夫电压定律（KVL）
对于任一集总参数电路中的任一回路，沿回路方向各部分电压的代数合为零：$\sum u = 0$。
实质是能量守恒的体现。

## 三、电阻电路的分析方法

### 3.1 等效变换
- **电阻串并联**：串联 $R_{eq} = \sum R_k$；并联 $\frac{1}{R_{eq}} = \sum \frac{1}{R_k}$。
- **Y-Δ变换**：
  - Y→Δ：$R_{12} = \frac{R_1 R_2 + R_2 R_3 + R_3 R_1}{R_3}$，对称轮换。
  - Δ→Y：$R_1 = \frac{R_{12} R_{31}}{R_{12}+R_{23}+R_{31}}$，对称轮换。
- **电源等效**：实际电压源（$U_s, R_s$ 串联）可等效为实际电流源（$I_s = U_s/R_s, R_s$ 并联）；受控源也可类似变换。

### 3.2 支路电流法
以支路电流为未知量，对 $n-1$ 个节点列 KCL，对 $b-(n-1)$ 个独立回路列 KVL，共 $b$ 个方程，求解所有支路电流。

### 3.3 网孔电流法
以网孔电流为变量。对每个网孔列写 KVL，方程形式：
$R_{11} i_{m1} + R_{12} i_{m2} + \cdots = u_{s11}$
- 自电阻为正，互电阻为负（相邻网孔电流参考方向均一致时）。
- 适用于平面电路。

### 3.4 节点电压法
以节点电压为变量。选定参考节点（零电位），对 $n-1$ 个独立节点列 KCL，方程形式：
$G_{11} u_{n1} + G_{12} u_{n2} + \cdots = i_{s11}$
- 自电导为正，互电导为负。
- 适用于含电流源的情况。

### 3.5 叠加定理
线性电路中，任一响应等于各独立源单独作用时响应的代数和。
- 单独作用时，其他独立电压源短路，独立电流源开路。
- 受控源保持不变。
- 功率不能直接叠加。

### 3.6 戴维南定理和诺顿定理
- **戴维南定理**：任一线性含源二端网络，对外可等效为电压源串联电阻。
  - 开路电压 $U_{oc}$：外电路断开时的端电压。
  - 等效电阻 $R_{eq}$：内部独立源置零后的入端电阻（可加电压求电流或短路电流法）。
- **诺顿定理**：等效为电流源 $I_{sc}$ 并联电阻 $R_{eq}$，其中 $I_{sc}$ 为短路电流。
- **最大功率传输**：负载 $R_L = R_{eq}$ 时获得最大功率 $P_{max} = \frac{U_{oc}^2}{4R_{eq}}$。

## 四、动态电路分析（一阶、二阶）

### 4.1 动态元件与换路定律
- **换路**：开关接入断开、参数突变的瞬间。
- **换路定则**：若电容电流有限，$u_C(0^+) = u_C(0^-)$；若电感电压有限，$i_L(0^+) = i_L(0^-)$。
- 初始值求解步骤：
  1. 换路前稳态，电容开路、电感短路，求 $u_C(0^-), i_L(0^-)$。
  2. 换路后，由换路定则得 $u_C(0^+), i_L(0^+)$。
  3. 换路后瞬间（$t=0^+$），电容用电压源替代，电感用电流源替代，求其它初始值。

### 4.2 一阶电路零输入响应
- **RC 电路零输入**：$u_C(t) = U_0 e^{-t/\tau}$，$\tau = RC$（时间常数）。
- **RL 电路零输入**：$i_L(t) = I_0 e^{-t/\tau}$，$\tau = L/R$。
- 响应由初始储能衰减，指数规律。

### 4.3 一阶电路零状态响应
- 外施激励作用下，初始储能为零。
- **RC 充电**（直流电压源 Us）：$u_C(t) = U_s (1 - e^{-t/\tau})$。
- **RL 激励**（直流电流源 Is）：$i_L(t) = I_s (1 - e^{-t/\tau})$。
- 全响应 = 零输入响应 + 零状态响应。

### 4.4 一阶电路三要素法
对于直流激励下的一阶电路，任意响应：
$f(t) = f(\infty) + [f(0^+) - f(\infty)] e^{-t/\tau}$
- $f(0^+)$：初始值。
- $f(\infty)$：稳态值。
- $\tau$：从动态元件两端看入的戴维南等效电阻计算时间常数。

### 4.5 二阶电路
- 含两个独立储能元件，用二阶微分方程描述。
- 典型 RLC 串联零输入响应：
  - 特征方程 $LC s^2 + RC s + 1 = 0$。
  - 欠阻尼、过阻尼、临界阻尼条件由特征根判别。
- 分析方法：列写微分方程，由初始条件确定常数。

## 五、正弦稳态电路分析

### 5.1 正弦量的相量表示
- 正弦量：$u(t) = U_m \cos(\omega t + \phi)$。
- 有效值：$U = U_m / \sqrt{2}$。
- **相量**：$\dot{U} = U \angle \phi$，对应时域的复数表示。
- 运算性质：加减对应平行四边形法则；微积分对应乘以 $j\omega$ 或除以 $j\omega$。

### 5.2 阻抗与导纳
- **阻抗**：$Z = R + jX$，$R$ 为电阻，$X$ 为电抗。$Z = \dot{U} / \dot{I}$。
- 元件：
  - 电阻：$Z_R = R$
  - 电感：$Z_L = j\omega L$（感抗 $X_L = \omega L$）
  - 电容：$Z_C = 1/(j\omega C) = -j/(\omega C)$（容抗 $X_C = 1/(\omega C)$）
- **导纳**：$Y = 1/Z = G + jB$，$G$ 电导，$B$ 电纳。
- 阻抗的串联、并联与电阻电路类似，使用复数运算。

### 5.3 正弦稳态电路的分析
- 基本定律相量形式：KCL $\sum \dot{I}=0$，KVL $\sum \dot{U}=0$。
- 节点法、网孔法、叠加定理、戴维南/诺顿定理等都扩展到相量域。
- **相量图**：定性分析工具。

### 5.4 功率
- **瞬时功率** $p(t) = u(t)i(t)$。
- **平均功率（有功功率）** $P = UI\cos\theta$，$\theta = \phi_u - \phi_i$ 为功率因数角。单位：瓦（W）。
- **无功功率** $Q = UI\sin\theta$，单位：乏（Var）。感性 $Q>0$，容性 $Q<0$。
- **视在功率** $S = UI = \sqrt{P^2+Q^2}$，单位：伏安（VA）。
- **复功率** $\tilde{S} = \dot{U} \dot{I}^* = P + jQ$。
- 功率因数 $\cos\theta$ 的改善：并联电容。

### 5.5 三相电路
- 对称三相电源：相位相差120°。
- Y 形连接：线电压 $\sqrt{3}$ 倍相电压，且超前 30°；线电流等于相电流。
- Δ形连接：线电压等于相电压；线电流为 $\sqrt{3}$ 倍相电流，落后 30°。
- 对称三相功率：$P = \sqrt{3} U_l I_l \cos\phi$。
- 不对称情况可用对称分量法或直接分析。

## 六、耦合电感和理想变压器

### 6.1 耦合电感
- 同名端：电流流进同名端，互感磁通相助。
- 电压-电流关系：
  - 时域：$u_1 = L_1 \frac{di_1}{dt} + M \frac{di_2}{dt}$，$u_2 = M \frac{di_1}{dt} + L_2 \frac{di_2}{dt}$，$M$ 为互感。
  - 相量：$\dot{U}_1 = j\omega L_1 \dot{I}_1 + j\omega M \dot{I}_2$，$\dot{U}_2 = j\omega M \dot{I}_1 + j\omega L_2 \dot{I}_2$。
- 耦合系数 $k = M/\sqrt{L_1 L_2} \le 1$。
- 去耦等效（T 型去耦）可用于分析。

### 6.2 理想变压器
- 条件：全耦合（$k=1$）、无损耗、无穷大磁导率。
- 变比 $n = N_1 / N_2$。
- 关系：$\frac{u_1}{u_2} = n$，$\frac{i_1}{i_2} = -\frac{1}{n}$（或根据同名端确定符号）。
- 阻抗变换：$Z_{in} = n^2 Z_L$。

## 七、网络函数与频率响应

### 7.1 网络函数
- 定义：$H(j\omega) = \frac{\text{响应相量}}{\text{激励相量}}$。
- 类型：转移电压比、转移电流比、转移阻抗、转移导纳等。

### 7.2 谐振
- **串联谐振**（RLC 串联）：
  - 条件：$\omega_0 L = 1/(\omega_0 C)$，谐振角频率 $\omega_0 = 1/\sqrt{LC}$。
  - 特性：阻抗最小 $|Z|=R$，电流最大，电压可高于电源电压 $Q$ 倍。
  - 品质因数 $Q = \frac{\omega_0 L}{R} = \frac{1}{R}\sqrt{\frac{L}{C}}$。
- **并联谐振**（GLC 并联）：
  - 谐振频率 $\omega_0 = 1/\sqrt{LC}$，导纳最小。
  - 品质因数 $Q = \frac{\omega_0 C}{G} = \frac{R}{\omega_0 L}$。
- 通频带：$BW = \omega_0 / Q$（3dB 带宽）。

### 7.3 滤波器
- 低通、高通、带通、带阻滤波器。
- 一阶、二阶有源/无源滤波器。

## 八、二端口网络

### 8.1 参数方程
- $Y$ 参数：$\begin{pmatrix} \dot{I}_1 \\ \dot{I}_2 \end{pmatrix} = \begin{pmatrix} Y_{11} & Y_{12} \\ Y_{21} & Y_{22} \end{pmatrix} \begin{pmatrix} \dot{U}_1 \\ \dot{U}_2 \end{pmatrix}$
- $Z$ 参数：$\begin{pmatrix} \dot{U}_1 \\ \dot{U}_2 \end{pmatrix} = \begin{pmatrix} Z_{11} & Z_{12} \\ Z_{21} & Z_{22} \end{pmatrix} \begin{pmatrix} \dot{I}_1 \\ \dot{I}_2 \end{pmatrix}$
- 传输参数 $T$ (ABCD) 和混合参数 $H$ 等。
- 对称性、互易性条件。
- 二端口的连接方式：级联（用 T 参数）、串联（用 Z 参数）、并联（用 Y 参数）。
