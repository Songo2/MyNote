标签:电化学是研究电能与化学能相互转化及其规律的科学，涉及电极过程、电解质溶液、界面现象以及相关的热力学和动力学。以下为系统学习电化学的要点梳理。

## 1. 基本概念与术语

### 1.1 电化学系统组成
- **电极**：电子导体（金属、碳材料、半导体），发生氧化或还原反应的场所。
- **电解质**：离子导体（溶液、熔融盐、固态电解质），负责离子传输。
- **外电路**：电子传输路径。
- **界面**：电极/电解质接触处，双电层形成区域。

### 1.2 氧化还原反应与半反应
- 氧化反应：失去电子，发生在阳极。
- 还原反应：得到电子，发生在阴极。
- 总反应可拆分为两个半反应，如锌铜原电池：
  - 阳极（氧化）：Zn → Zn²⁺ + 2e⁻
  - 阴极（还原）：Cu²⁺ + 2e⁻ → Cu

### 1.3 法拉第定律
- 第一定律：电极上发生化学变化的物质质量与通过的电量成正比。
- 第二定律：通过相同电量时，各电极上反应的物质质量与化学当量（M/n）成正比。
- 公式：m = (Q × M) / (n × F)，其中F = 96485 C/mol（法拉第常数）。

### 1.4 电流与电势符号惯例
- **阳极电流为正，阴极电流为负**（IUPAC惯例）。
- 电势以标准氢电极（SHE）为参考。

## 2. 电化学热力学

### 2.1 电池电动势与吉布斯自由能
- 最大电功：Wₑₗₑ = nFE_cell
- 恒温恒压下：ΔG = -nFE_cell
- 标准状态：ΔG° = -nFE_cell°
- 电动势与平衡常数关系：E_cell° = (RT/nF) lnK

### 2.2 能斯特方程
对于半反应 aOx + ne⁻ ⇌ bRed：
E = E° - (RT/nF) ln(a_Red^b / a_Ox^a)
常温（25°C）：E = E° - (0.0592/n) log₁₀(a_Red^b / a_Ox^a)

### 2.3 电极电势与参比电极
- **标准氢电极（SHE）**：定义为零点，难以实用。
- 常用参比电极：
  - 饱和甘汞电极（SCE）：E = 0.241 V vs SHE
  - 银/氯化银电极（Ag/AgCl）：E = 0.197 V（饱和KCl） vs SHE
- 电极电势越高，氧化态易被还原（强氧化剂）；越低，还原态易被氧化（强还原剂）。

### 2.4 电动势测定与pH的关系
- pH对氢电极电势的影响：E_H₂ = -0.0592 pH（25°C）
- 构建pH计原理。

## 3. 电极/溶液界面结构与双电层

### 3.1 双电层模型
- **Helmholtz 紧密层模型**：反离子紧密排列在电极表面。
- **Gouy-Chapman 扩散层模型**：反离子浓度呈玻尔兹曼分布。
- **Stern 模型**：内紧密层（Helmholtz层）+ 扩散层。
- 零电荷电位（PZC）：界面净电荷为零时的电极电势。

### 3.2 电毛细现象与界面张力
- 电毛细曲线：界面张力随电极电势的变化，PZC处最大。

### 3.3 特性吸附
- 离子或分子在电极表面的非静电吸附，影响双电层结构。

## 4. 电化学动力学

### 4.1 电极过程基本步骤
1. 液相传质（反应物向电极表面输送）。
2. 前置化学转化（可能在表面或溶液中进行）。
3. 电子转移步骤（核心步骤，法拉第过程）。
4. 后继化学转化。
5. 产物脱附、新相生成等。

### 4.2 电荷转移动力学与Butler-Volmer方程
- 过电位η：E - E_eq，偏离平衡电势的程度。
- 对于简单反应 O + ne⁻ ⇌ R：
  电流密度 i = i₀ [exp(-α_c nFη/RT) - exp(α_a nFη/RT)]
  - i₀ 交换电流密度，反映平衡时反应速率。
  - α_c，α_a 阴极和阳极传递系数（α_c + α_a = 1，常用α≈0.5）。
- 低过电位时（η < 10 mV），线性近似：i ≈ i₀ (nF/RT) η，电荷转移电阻 R_ct = RT/(nFi₀)。
- 高过电位时，Tafel 公式：η = a + b log|i|，其中 b = 2.303RT/(αnF)（阴极）或 -2.303RT/(βnF)（阳极）。

### 4.3 扩散控制过程
- 浓差过电位：由于传质限制导致的电位偏移。
- 极限扩散电流密度（i_l）：
  对于平面电极：i_l = nF D C_b / δ（δ 扩散层厚度）
- 旋转圆盘电极（RDE）稳态扩散层厚度：δ = 1.61 D^(1/3) ν^(1/6) ω^(-1/2)，i_l 与 ω^(1/2) 成正比（Levich方程）。

### 4.4 混合控制与Koutecký-Levich分析
1/i = 1/i_k + 1/i_l，i_k 为动力学电流，可分离电荷转移与扩散效应。

## 5. 电化学测量技术

### 5.1 稳态技术
- **计时电位法/计时电流法**：控制电流或电势，记录响应。
- **线性扫描伏安法（LSV）**：电势线性扫描，记录电流。
- **循环伏安法（CV）**：三角波电势扫描，研究反应可逆性、中间体。
  - 可逆波判据：E_p,a - E_p,c ≈ 57/n mV，i_p ∝ v^(1/2)。
  - 吸附控制时：i_p ∝ v，峰形对称。

### 5.2 暂态技术
- **电位阶跃/计时安培法**：Cottrell方程 i(t) = nFAC_b (D/πt)^(1/2)（半无限扩散）。
- **电化学阻抗谱（EIS）**：施加小振幅正弦扰动，测量阻抗频谱，获取R_s、R_ct、C_dl、Warburg阻抗等信息。常用Nyquist图、Bode图。

### 5.3 流体动力学技术
- 旋转圆盘电极（RDE）、旋转环盘电极（RRDE）：用于研究反应机理、检测中间体。

## 6. 常见电化学体系与应用

### 6.1 一次电池与二次电池
- 一次电池：锌锰干电池、锂亚硫酰氯电池等。
- 二次电池（可充电）：
  - 铅酸电池：Pb + PbO₂ + 2H₂SO₄ ⇌ 2PbSO₄ + 2H₂O
  - 锂离子电池：嵌入/脱出反应，正极LiCoO₂、LiFePO₄，负极石墨。
  - 关键参数：比容量、能量密度、功率密度、库仑效率、循环寿命。

### 6.2 燃料电池
- 氢氧燃料电池：H₂ → 2H⁺ + 2e⁻（阳极），1/2O₂ + 2H⁺ + 2e⁻ → H₂O（阴极）。
- 类型：质子交换膜燃料电池（PEMFC）、固体氧化物燃料电池（SOFC）。
- 效率不受卡诺循环限制。

### 6.3 电化学传感器
- 电位型传感器：离子选择性电极（pH电极、氟离子电极）。
- 电流型传感器：葡萄糖传感器（利用葡萄糖氧化酶）。

### 6.4 腐蚀与防护
- 电化学腐蚀：金属表面形成微电池（氧浓差电池、异种金属接触）。
- 防护方法：阴极保护（牺牲阳极、外加电流）、阳极保护、涂层、缓蚀剂。
- 腐蚀电位与腐蚀电流：用Tafel外推法或线性极化法测定。

### 6.5 电化学合成
- 氯碱工业：电解食盐水生产Cl₂、H₂和NaOH。
- 有机电合成：如己二腈合成。
