## 一、机械波概述
- **定义**：机械振动在介质中的传播过程，称为机械波。
- **产生条件**：
    1. 波源（振动的物体）
    2. 弹性介质（能够传播机械振动的物质）
- **本质**：传播的是振动形式和能量，介质本身并不随波迁移（各质点只在平衡位置附近振动）。
- **注意**：机械波不能在真空中传播，因为它依赖介质。

## 二、机械波的分类
根据质点振动方向与波的传播方向的关系：
- **横波**：
    - 质点振动方向与波的传播方向垂直。
    - 例如：绳波、水面波（表面波）。
    - 波形特征：凸起（波峰）和凹下（波谷）。
- **纵波**：
    - 质点振动方向与波的传播方向在同一直线上。
    - 例如：声波、弹簧中的疏密波。
    - 波形特征：稀疏部（疏部）和稠密部（密部）。
- 地震波既有横波（S波）又有纵波（P波）。

## 三、描述波动的物理量
1. **波长（$\lambda$）**
    - 振动相位总是相同的两个相邻质点间的距离。
    - 横波中，相邻波峰（或波谷）间的距离；纵波中，相邻密部（或疏部）间的距离。
    - 单位：米（m）。

2. **周期（$T$）与频率（$f$）**
    - **周期**：波传播一个波长所需的时间；也是介质中各质点完成一次全振动的时间，由波源决定。
    - **频率**：周期的倒数，即单位时间内完成全振动的次数，同样取决于波源。
    - 关系：$T = \frac{1}{f}$，单位：秒（s），赫兹（Hz）。

3. **波速（$v$）**
    - 振动形式在介质中传播的速度。
    - 决定因素：介质本身的性质（如密度、弹性模量），与波源的频率无关。
    - 关系式：$v = \frac{\lambda}{T} = \lambda f$
    - 注意：波由一种介质进入另一种介质时，频率不变，波速和波长变化。

4. **振幅（$A$）**
    - 质点偏离平衡位置的最大距离，表示振动的强弱，也反映波的能量大小。

## 四、波的图像
- **波动图像（y-x图像）**：描述某一时刻介质中各个质点偏离平衡位置的位移随位置变化的关系。
- **振动图像（y-t图像）**：描述某一个质点在不同时刻的位移。
- 两种图像的区别：
    | 对比项 | 振动图像（y-t） | 波动图像（y-x） |
    |--------|----------------|----------------|
    | 研究对象 | 一个质点 | 许多质点 |
    | 横坐标 | 时间 t            | 位置 x            |
    | 纵坐标 | 质点位移 y        | 质点位移 y        |
    | 图像信息 | 周期T、振幅A、某时刻位移 | 波长λ、振幅A、某时刻各质点的位移 |
    | 图像变化 | 随时间延伸          | 沿传播方向平移 |
    | 完整曲线 | 一个周期的形状      | 一个波长的形状      |

## 五、波动方程
简谐波的波动方程（沿x轴正方向传播）：
$$y = A \sin \left( \omega t - \frac{2\pi x}{\lambda} + \varphi_0 \right)$$
或
$$y = A \sin \left( 2\pi (f t - \frac{x}{\lambda}) + \varphi_0 \right)$$
其中：
- $y$：坐标为x的质点在t时刻的位移。
- $\omega = 2\pi f$：角频率。
- $\varphi_0$：原点处质点的初相。

## 六、波的衍射、反射、折射和干涉
### 1. 波的反射
- 波遇到障碍物会返回来继续传播的现象。
- 遵循反射定律：入射角等于反射角，入射线、反射线和法线在同一平面内。

### 2. 波的折射
- 波从一种介质斜射入另一种介质时，传播方向发生改变的现象。
- 折射定律：$\frac{\sin i}{\sin r} = \frac{v_1}{v_2}$（i入射角，r折射角，v1、v2分别为两种介质中的波速）。
- 频率不变，波速和波长改变。

### 3. 波的衍射
- 波绕过障碍物继续传播的现象。
- 明显衍射条件：障碍物或孔的尺寸比波长小，或者与波长差不多。
- 波长越长越容易衍射。

### 4. 波的干涉
- 两列频率相同、振动方向相同、相位差恒定的波（相干波）相遇叠加，使某些区域振动加强，某些区域振动减弱，形成稳定的分布图样。
- **干涉条件**：同频率、同振动方向、恒定相位差。
- **振动加强点**：到两波源的距离差等于波长的整数倍，$\Delta r = k\lambda$（k=0,±1,±2,…）。
- **振动减弱点**：到两波源的距离差等于半波长的奇数倍，$\Delta r = (2k+1)\frac{\lambda}{2}$。
- 干涉是波特有的现象。

## 七、多普勒效应
- **定义**：当波源和观察者之间有相对运动时，观察者接收到的频率与波源发出的频率不同的现象。
- **规律**：
    - 波源与观察者相互靠近时，接收频率变高。
    - 相互远离时，接收频率变低。
- **应用**：测速仪、彩超、宇宙红移（光波的多普勒效应）等。
- 注意：波源的频率本身并没有改变，只是观察者接收到的频率发生了变化。

## 八、驻波（补充）
- 两列振幅相同、传播方向相反的相干波叠加而成的特殊的干涉现象。
- 波形不向前移动，某些点始终静止（波节），某些点振幅最大（波腹）。
- 相邻波节（或波腹）间的距离为 $\frac{\lambda}{2}$。
- 常见于弦振动、管乐器中的空气柱振动。

## 九、典型应用与公式总结
- **波速公式**：$v = \lambda f$，同一列波在不同介质中频率不变。
- **波上质点的振动方向判断**：微平移法、三角形法（或“同侧法”）。
- **能量特征**：波传播的是振动形式和能量，各质点只在平衡位置附近振动，不随波迁移。
- **波形图随时间的变化**：经过时间 $\Delta t$，波沿传播方向移动距离 $\Delta x = v \Delta t$，波形沿传播方向平移。

机械波不仅是物理学的基础内容，也是理解声学、电磁波、光学等现象的基石。熟练掌握波动图像与振动图像的转换、干涉条件的分析以及多普勒效应的计算，对后续学习至关重要。
