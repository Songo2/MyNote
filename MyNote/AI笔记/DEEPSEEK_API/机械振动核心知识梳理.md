## 1. 振动的基本概念
机械振动是指物体（或系统）在平衡位置附近所做的往复运动。按不同分类方式，振动可分为：
- **自由振动**：系统仅受初始扰动，无外部持续激励。
- **受迫振动**：系统在持续外部激励下振动。
- **有阻尼振动**：存在能量耗散（如粘性阻尼、干摩擦）。
- **无阻尼振动**：忽略能量耗散的理想模型。
- **线性振动**：恢复力、阻尼力与位移、速度成正比，满足叠加原理。
- **非线性振动**：刚度或阻尼呈现非线性特性，可能出现分岔、混沌。

工程中多数振动可简化为质量‑弹簧‑阻尼模型，即**单自由度（SDOF）系统**。对于连续体或复杂结构，需用**多自由度（MDOF）系统**或**连续系统**描述。

## 2. 单自由度系统振动

### 2.1 无阻尼自由振动
运动方程：  
$$ m\ddot{x} + kx = 0 \quad\text{或}\quad \ddot{x} + \omega_n^2 x = 0 $$  
其中固有圆频率  
$$ \omega_n = \sqrt{\frac{k}{m}} $$  
通解：  
$$ x(t) = A\cos\omega_n t + B\sin\omega_n t = X\cos(\omega_n t - \phi) $$  
振幅 $X = \sqrt{A^2+B^2}$，初相位 $\phi = \arctan(B/A)$。  
$m$ — 质量，$k$ — 刚度。固有频率仅由系统物理参数决定。

### 2.2 有阻尼自由振动
引入阻尼比 $\zeta = \frac{c}{2\sqrt{km}} = \frac{c}{2m\omega_n}$，运动方程为：  
$$ m\ddot{x} + c\dot{x} + kx = 0 \quad\Rightarrow\quad \ddot{x} + 2\zeta\omega_n\dot{x} + \omega_n^2 x = 0 $$  
特征根： $s_{1,2} = -\zeta\omega_n \pm \omega_n\sqrt{\zeta^2-1}$

按阻尼比大小分为三种情况：
| 阻尼状态 | 条件          | 响应形式                                                     |
| -------- | ------------- | ------------------------------------------------------------ |
| 欠阻尼   | $0<\zeta<1$   | 衰减振荡：$x(t)=X e^{-\zeta\omega_n t}\cos(\omega_d t-\phi)$，$\omega_d=\omega_n\sqrt{1-\zeta^2}$ |
| 临界阻尼 | $\zeta=1$     | 无振荡，最快返回平衡：$x(t)=(A_1+A_2 t)e^{-\omega_n t}$           |
| 过阻尼   | $\zeta>1$     | 无振荡，缓慢衰减：$x(t)=A_1 e^{s_1 t}+A_2 e^{s_2 t}$             |

常见结构 $\zeta$ 很小（金属结构约 0.01~0.05），可认为 $\omega_d \approx \omega_n$。

### 2.3 简谐受迫振动与共振
设简谐激励力 $F(t)=F_0\sin\omega t$，运动方程：  
$$ m\ddot{x} + c\dot{x} + kx = F_0\sin\omega t $$  
稳态响应为与激励同频的简谐振动，滞后相位 $\phi$：  
$$ x(t) = X\sin(\omega t - \phi) $$  
**放大因子**（动力系数） $\beta = \frac{X}{F_0/k} = \frac{1}{\sqrt{(1-r^2)^2 + (2\zeta r)^2}}$  
其中频率比 $r = \omega/\omega_n$。  
相位角：$\phi = \arctan\frac{2\zeta r}{1-r^2}$。

- 当 $r \to 0$：$\beta \approx 1$，响应近似静态变形。
- 当 $r \to 1$ 且阻尼较小时，$\beta$ 急剧增大，发生**共振**。共振峰对应频率 $r_{\text{peak}} = \sqrt{1-2\zeta^2}$（仅当 $\zeta < 1/\sqrt{2}$ 时存在）。共振放大系数 $\beta_{\max} \approx \frac{1}{2\zeta\sqrt{1-\zeta^2}}$。
- 当 $r \gg 1$：$\beta \to 0$，系统惯性占主导。

**品质因数** $Q \approx \frac{1}{2\zeta}$，常用于衡量共振尖锐程度。

### 2.4 基础运动与隔振
- **支座激励**：基础位移 $y(t)=Y\sin\omega t$，运动方程为 $m\ddot{x}+c\dot{x}+kx = ky+c\dot{y}$。  
  相对位移传递率（位移振幅比）为 $\frac{X}{Y}$，表达式与受迫振动放大因子相同。  
- **力传递率（隔振）**：传递给基础的力幅与激励力幅之比  
  $$ TR = \frac{F_T}{F_0} = \sqrt{\frac{1+(2\zeta r)^2}{(1-r^2)^2+(2\zeta r)^2}} $$  
  当 $r > \sqrt{2}$ 时 $TR<1$，起隔振效果；阻尼在 $r>\sqrt{2}$ 时反而增大传递率，设计时需权衡。

## 3. 多自由度系统（MDOF）与模态分析

### 3.1 运动方程
对 $n$ 自由度系统，可写为矩阵形式：  
$$ [M]\{\ddot{x}\} + [C]\{\dot{x}\} + [K]\{x\} = \{F(t)\} $$  
$[M]$ — 质量矩阵（正定），$[K]$ — 刚度矩阵（半正定或正定），$[C]$ — 阻尼矩阵。

### 3.2 固有频率与主振型
无阻尼自由振动方程： $[M]\{\ddot{x}\}+[K]\{x\}=\{0\}$。  
设同步运动 $\{x\}=\{\varphi\}\sin(\omega t+\phi)$，代入得特征值问题：  
$$ ([K] - \omega^2[M])\{\varphi\} = \{0\} $$  
非零解条件：  
$$ \det([K] - \omega^2[M]) = 0 $$  
解得 $n$ 个固有频率 $\omega_1, \omega_2, \dots, \omega_n$（设 $0 \le \omega_1 \le \omega_2 \le \dots$），对应特征向量 $\{\varphi\}_i$ 即**主振型**（模态向量）。  
振型具有正交性：  
$$ \{\varphi\}_i^T[M]\{\varphi\}_j = 0, \quad \{\varphi\}_i^T[K]\{\varphi\}_j = 0 \quad (i \ne j) $$

### 3.3 模态叠加法
通过坐标变换 $\{x\} = [\Phi]\{q\}$（$[\Phi]$ 为振型矩阵），可解耦方程组：  
$$ \ddot{q}_i + 2\zeta_i \omega_i \dot{q}_i + \omega_i^2 q_i = \frac{\{\varphi\}_i^T \{F\}}{m_i} $$  
其中 $m_i = \{\varphi\}_i^T[M]\{\varphi\}_i$ 为模态质量，$\zeta_i$ 为模态阻尼比。  
此时原多自由度系统转化为 $n$ 个独立的单自由度系统，可分别求解再叠加，大大简化分析。

## 4. 连续系统与非线性简介
- **连续系统**（弦、杆、梁）振动由偏微分方程描述，具有无穷多个固有频率和模态，例如：  
  张紧弦振动方程 $\frac{\partial^2 y}{\partial t^2}=c^2 \frac{\partial^2 y}{\partial x^2}$，固有频率 $\omega_n = \frac{n\pi c}{L}$。
- **非线性振动**：恢复力或阻尼非线性时，出现多平衡点、自激振动、跳跃现象、内共振等。常用方法有摄动法、平均法、数值仿真。
- **随机振动**：输入不确定时用时域/频域统计方法，功率谱密度、均方根响应等。

## 5. 工程设计与避免共振策略
- 调整固有频率，避开工作频率（$r \ll 1$ 或 $r \gg 1$）。
- 增加阻尼：使用阻尼材料、阻尼器或连接结构的摩擦耗能。
- 动态吸振器：附加质量‑弹簧系统，在特定频率下使主系统振幅为零。
- 模态避让：修改结构刚度/质量分布，改变振型节点位置。

## 7. 总结
机械振动分析的核心是建立运动方程 → 识别固有特性（频率、模态） → 评估动态响应 → 实现振动控制。从单自由度到多自由度，再到连续系统，逐步逼近真实结构。阻尼决定了共振幅度和衰减快慢，频率比主导响应大小。掌握这些基本概念和数学工具，是进行机械结构动力学设计、故障诊断与减振降噪的基础。
