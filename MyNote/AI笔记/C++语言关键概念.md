# C语言关键概念

## 1. 指针
- 指针是一种变量，存储内存地址
- 可以通过指针修改变量值
- 用于动态内存分配、函数参数传递等
- 示例：
  ```c
  int a = 5;
  int *p = &a;
  *p = 10; // 修改a的值
  ```

## 2. 内存
- 计算机中的存储区域，分为栈、堆、静态区等
- 栈：存储局部变量和函数调用信息
- 堆：动态分配内存，手动管理
- 静态区：全局变量和静态变量存储区

## 3. 编译链接
- 编译：将源代码转换为目标代码（汇编）
- 链接：将多个目标文件和库链接成可执行文件
- 步骤：
  1. 预处理（宏替换）
  2. 编译
  3. 链接

## 4. 宏
- 使用#define定义的文本替换
- 在预处理阶段进行替换
- 示例：
  ```c
  #define PI 3.14159
  double area = PI * r * r;
  ```
- 注意：避免宏带来的副作用，使用`##`和`...`进行变参宏定义

## 5. 复合类型
- 包含多种基本类型的组合
- 常见复合类型：
  - 数组：相同类型的元素集合
  - 结构体：不同类型的元素组合
  - 共用体：内存中同一区域的不同视图
  - 枚举：定义一组命名的整数常量

每个概念在C语言编程中都有重要作用，理解它们有助于编写更高效、更安全的代码。
