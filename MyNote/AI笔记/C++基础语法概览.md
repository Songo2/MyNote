# C++基础语法概览

创建时间：2026-05-07 13:12

## 1. 预处理指令 (Preprocessor Directives)

*   **`#include`**:  引入头文件，包含其他文件定义的函数、类、变量等。  例如 `#include <iostream>` 引入标准输入输出流。
*   **`#define`**:  预处理器宏定义，通常用于定义常量或简单的代码片段。  例如 `#define PI 3.14159`。  注意：使用 `#define` 的宏定义可能会导致命名空间污染和潜在的调试困难。
*   **`#ifdef`, `#ifndef`, `#else`, `#endif`**:  预处理器条件编译指令，根据条件选择性地编译代码。

## 2. 命名空间 (Namespaces)

*   用于避免命名冲突，将代码组织到不同的命名空间中。
*   例如 `using namespace std;` 允许使用 `std` 命名空间中的元素，如 `cout` 和 `cin`。
*   也可以使用 `std::cout` 和 `std::cin` 来明确指定使用 `std` 命名空间中的元素。

## 3. 数据类型 (Data Types)

*   **基本数据类型**:
    *   `int`:  整型 (通常是 32 位)
    *   `float`:  单精度浮点型
    *   `double`:  双精度浮点型
    *   `char`:  字符型
    *   `bool`:  布尔型 (true 或 false)
*   **用户自定义数据类型**:
    *   `struct`:  结构体，用于组合不同类型的成员。
    *   `class`:  类，用于封装数据和成员函数，实现封装、继承和多态。
    *   `enum`:  枚举类型，用于定义一组相关的常量值。

## 4. 变量与常量 (Variables and Constants)

*   **变量**:  存储数据的名称，其值在程序执行期间可以改变。
    *   声明变量： `int age;`
    *   初始化变量： `int age = 30;`
*   **常量**:  存储数据的名称，其值在程序执行期间不会改变。
    *   `const int max_value = 100;`
    *   可以使用 `constexpr` 关键字在编译时计算常量值。

## 5. 运算符 (Operators)

*   **算术运算符**:  `+`, `-`, `*`, `/`, `%` (取模)
*   **关系运算符**:  `==` (等于), `!=` (不等于), `>`, `<`, `>=`, `<=`
*   **逻辑运算符**:  `&&` (与), `||` (或), `!` (非)
*   **位运算符**:  `&`, `|`, `^`, `~`, `<<`, `>>`  （用于对二进制位进行操作）
*   **赋值运算符**:  `=`, `+=`, `-=`, `*=`, `/=`, `%=`

## 6. 控制流程 (Control Flow)

*   **`if-else` 语句**:  根据条件执行不同的代码块。
    ```c++
    if (condition) {
        // 满足条件时执行的代码
    } else {
        // 不满足条件时执行的代码
    }
    ```
*   **`switch-case` 语句**:  根据变量的值选择不同的代码块。
    ```c++
    switch (expression) {
        case value1:
            // 执行的代码
            break;
        case value2:
            // 执行的代码
            break;
        default:
            // 默认执行的代码
    }
    ```
*   **`for` 循环**:  重复执行一段代码，指定循环次数。
    ```c++
    for (int i = 0; i < 10; i++) {
        // 执行的代码
    }
    ```
*   **`while` 循环**:  只要条件为真，就一直重复执行一段代码。
    ```c++
    while (condition) {
        // 执行的代码
    }
    ```
*   **`do-while` 循环**:  至少执行一次一段代码，然后只要条件为真，就一直重复执行。
    ```c++
    do {
        // 执行的代码
    } while (condition);
    ```
*   **`break` 语句**:  跳出循环。
*   **`continue` 语句**:  跳过当前循环的剩余代码，直接进入下一次循环。

## 7. 函数 (Functions)

*   **函数定义**:  定义一个函数的名称、参数类型、返回值类型和函数体。
    ```c++
    return_type function_name(parameter_type parameter_name) {
        // 函数体
        return value; // 如果有返回值
    }
    ```
*   **函数调用**:  使用函数名称和参数值来调用函数。
*   **函数重载**:  允许存在多个同名函数，但参数列表不同。
*   **递归函数**:  函数调用自身。

## 8. 数组 (Arrays)

*   存储相同数据类型的元素，元素之间通过索引访问。
*   例如 `int numbers[5] = {1, 2, 3, 4, 5};`

## 9. 指针 (Pointers)

*   存储其他变量的内存地址。
*   `int *ptr;`  声明一个指向整型变量的指针。
*   `ptr = &variable;`  将变量的地址赋给指针。
*   `*ptr = value;`  通过指针访问并修改变量的值。

## 10. 引用 (References)

*   类似于指针，但更简洁，不需要使用 `*` 运算符。
*   `int &ref = variable;`  声明一个引用，引用指向整型变量。

## 11. 类 (Classes)

*   **成员变量**:  存储类的数据。
*   **成员函数**:  定义类的行为。
*   **构造函数**:  在创建类的对象时自动调用，用于初始化对象的成员变量。
*   **析构函数**:  在销毁类的对象时自动调用，用于释放对象占用的资源。
