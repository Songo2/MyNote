
# 基础知识

## 半导体

### 本征半导体

半导体是导电能力介于导体和绝缘体之间的材料

本征半导体指的是化学成分纯净的具有晶体结构的半导体,常见本征半导体含有硅,锗这种四价元素,还有金属氧化物,金属硫化物

四价元素最外层电子层有四个电子,它可以和其他原子共用电子形成共价键,根据八隅体规则,形成八电子稳定结构

我们以硅原子举例,则它周围会有另外4个硅原子与它形成共价键,形成晶体结构

价电子无法导电,那么本征半导体的载流子是什么

在热运动的作用下,价电子有可能逃逸出共价键的束缚,变成自由电子,同时在共价键里留下一个空穴,我们称这种现象为本征激发,这样产生的自由电子就可以导电

而空穴也可以导电,在外加电场是作用下,其他的电子被吸引进入空穴,产生新的空穴,这样等价于空穴的定向移动,故而空穴也可以作为载流子

本征激发越多,导电能力越好

对应本征激发,还有一种复合的现象,自由电子在运动时有可能进入空穴,形成共价键,导致这一堆自由电子空穴对湮灭,自由电子重新变为价电子,这个过程称为复合

本征激发和复合的速度,以及温度决定了载流子的浓度,载流子的浓度跟半导体的导电能力有关

温度升高,载流子的浓度会从一个水平升高到另一个水平,在一段时间后到达平衡状态后稳定下来,这个过程是怎么到达的

我们设想两个相关性,温度越高本征激发越快,浓度越高复合越快,所以在升高温度时,本征激发先加强,随后浓度升高导致复合加快,形成负反馈直到本征激发和复合动态平衡,中间的差额就导致了载流子浓度的升高

目前来说我们还不清楚半导体在工程上该怎么应用,这也是之前人们基本不发展半导体的原因
___
### 杂质半导体

然而半导体材料具有可掺杂性或可扩散性,人们花费了巨大的精力发展出了掺杂工艺和扩散工艺,因此我们可以在纯净的本征半导体里去扩散一些其他的元素来构成杂质半导体

杂质半导体就是在本征半导体里掺入少量的杂质元素
___
#### N型半导体

为了提高载流子,我们在本征半导体里掺入少量磷这类五价元素,少量的掺杂不会改变半导体的晶格结构,也就是有少量的磷取代了硅的位置,而五价的磷会导致形成4个共价键后多出一个自由电子,这使得半导体里的载流子浓度大幅度上升,磷施予了半导体自由电子这种载流子,这类原子也称为施主原子

此时自由电子是多数载流子,称为多子,对应的,空穴称为少子,主要的载流子是自由电子,电子带负电,因此这种半导体称为N(Negative)型半导体

由于此时半导体里自由电子主要来自于磷,本征激发和复合的自由电子远远少于这部分,故而温度变化对它(多子)几乎没有影响,而空穴的数量很少,它(少子)对温度很敏感
___
#### P型半导体

对应的,有P(Passive)型半导体,它的多子是空穴,这种半导体是我们通过在本征半导体掺入少量的硼这类三价原子形成,它提供了额外的空穴
___
### PN结

我们经过一系列研究,创造出这两种半导体,它也只是具有近似导体的导电能力,这显然不是我们真正想要的,而奇迹发生在这两种半导体的结合

当我们把P型半导体和N型半导体放在一起,P型半导体的空穴和N型半导体的自由电子将发生扩散运动,相互进入彼此,它们将相互湮灭,从而在交界处附近消耗载流子,形成一个空间电荷区,这部分几乎没有载流子

在空间电荷区的两端分别是P区和N区,它们一个电位高,一个电位低,在空间电荷区里形成一个从N区指向P区电场,阻止载流子扩散湮灭

空间电荷区有几个作用:因为载流子在这里几乎消耗殆尽,也称为耗尽层,因为它阻碍载流子继续扩散,也称为阻挡层,它是P区和N区的交结处,所以也称为PN结

在PN结载流子并非完全不扩散,电场在空间形成电势,这个电势对载流子而言相当于势垒,也就是说自由电子和空穴在PN结这个堤坝的两边翻涌,有部分载流子可以跨过势垒去到另一边

而对于少子,电势给了它一个势谷,它可以轻而易举地进入PN结,而进入后将被直接牵引到另外一边补充载流子,这称为漂移运动

因此多子的扩散运动会和少子的漂移运动相抵消

如果P区和N区的掺杂浓度相同,则形成对称结,即空间电荷区在P区和N区所占的空间是对称的,如果掺杂浓度不同则不对称,空间电荷区在P区和N区的宽窄不同,浓度高的窄,浓度低的宽

这样我们让PN结不导电了,但PN结有一个更重要的特性,它具有单向导电性
___
我们给PN结外加正向电压,也即从P区指向N区的电压,它会削弱PN结的内电压

我们调节外电压

从零开始提升电压,有一段区域是无法产生电流的,我们称之为死区,在提升到一定程度时,电流会突然暴增,几乎成指数增长

因为外加电压相当于在降低堤坝,让载流子逐渐地涌向彼此,当到达某个阈值时,扩散运动恢复,电流迅速增大

为了防止PN结被激增的电流烧掉,我们给电路加一个电阻,利用电阻的VCR限制电流

如果我们PN结外加反向电压,则内外电压一致,PN结越来越厚,阻挡作用越来越强,几乎不导电,但并非没有电流,因为漂移运动会被加强,但少子很少,几乎可以忽略,但它对温度特别敏感,它称为反向饱和电流

这就是PN结的单向导电性

由此我们可以做出PN结的伏安特性曲线

```tikz
\usepackage{circuitikz}
\begin{document}
\begin{circuitikz}[american]
\ctikzset{resistor=european}
	\draw[->] (-3,0) -- (5,0);
	\draw[->] (0,-0.5) -- (0,8);

	\draw (5,0) node[below]{$u$};

```

还有PN结的电流方程
$$
i=I_{S}(e^{\frac{u}{U_{T}}}-1)
$$
其中$I_{S}$是反向饱和电流,$U_{T}$是温度当量,它与温度相关,室温为$2.6mV$,一般来说导通电压,锗管是$0.2V-0.3V$,硅管是$0.6V-0.7V$,这时$\frac{u}{U_{T}}$很大,减一几乎可以忽略,所以它几乎是一个指数关系

PN结的伏安特性,在正向特性上存在死区和导通区,在反向特性上有反向饱和电流

当反向电压到达一定的范围时,将出现同样指数增长的一个反向电流,这称为反向击穿,反向击穿有两种

第一种称为雪崩击穿,当掺杂浓度低时,空间电荷区的距离比较长,相当于一个粒子加速器,一个自由电子进入后被加速,撞击价电子破环共价键,产生新的自由电子,随后继续撞击共价键,以类似链式反应的形式产生大量的自由电子

第二种称为齐纳击穿,当掺杂浓度高时,空间电荷区窄,导致场强很大,价电子直接从共价键中被拉出

反向击穿后产生大量自由电子,电流极大,导致PN结极速发热直接烧掉,如果可以控制不被烧毁,不发生二次击穿则PN结可以恢复

反向击穿的工作状态可以保持在很大的电流下有微小的电压变化,可以用于稳定电压,制作稳压二极管

温度越高,雪崩击穿所需的电压越高,而齐纳击穿所需的电压越低,因为温度高,热运动剧烈,价电子更容易被牵引出来,而晶格结构会变化导致空间电荷区变窄,雪崩击穿需要更高的电压进行加速

通过控制掺杂浓度,可以调节反向击穿电压的大小,浓度越低,击穿电压越高,通过不同的掺杂浓度和工艺,可以获得不同稳定电压的PN结
___
PN结两端的反向电压增大时,PN结的电荷量越来越大,表现出一种电容特性,这个电容发生在势垒上,称为势垒电容,势垒电容是非线性的,它可以作为可变电容

```tikz
\usepackage{circuitikz}
\begin{document}
\begin{circuitikz}[american]

```

而正向导通时,扩散的另外的区域的载流子实际是这个区域的少子,由于这不是平衡状态下该区域本身的少子,我们称之为非平衡少子,而正向电压越大,非平衡少子越多,故而这也等效出一个电容效应,称为扩散电容

## 半导体二极管

将PN结进行封装,从P区,N区引出电极,称为二极管,符号如下

```tikz
\usepackage{circuitikz}
\begin{document}
\begin{circuitikz}[american,scale=2]
\ctikzset{resistor=european}
	\draw (0,0) to[D-] ++(2,0);
\end{circuitikz}
\end{document}
```

二极管的伏安特性几乎和PN结是一样的,和PN结有两点不同

第一点是体电阻的存在,导致在相同电压下电流比PN结小
第二点是外壳存在泄露电流,导致反向电流比PN结大

温度升高,PN结的正向特性向左移,反向特性向下移,室温下,每升高1摄氏度,正向压降减小$2-2.5mV$,升高10摄氏度,反向电流增大一倍

正向特性是我们二极管单向导电性使用的地方,单向导电性使得我们可以规定电流的路径,我们可以把交流变为直流,这就是整流

而且正向导通区的电压变化很小,我们几乎可以认为在正向导通时电压不变,故而正向导通时,二极管也有稳压和前置电位作用

反向特性的饱和电流对温度的敏感性可以用于制作温度传感器,反向击穿的工作状态可以保持在很大的电流下有微小的电压变化,可以用于稳定电压,制作稳压二极管
___
### 二极管的主要参数

最大整流电流$I_{F}$,是二极管长期工作时能通过的正向平均电流的最大值,代表二极管工作时能通过的最大功率电流值

最高反向工作电压$U_{R}$,是二极管反向截止特性能稳定生效的最大电压,一般是反向击穿电压的一半

反向电流$I_{R}$,$I_{R}$越小,反向截止的效果越好

最高工作频率$f_{M}$,也称为上限频率,由于PN结存在结电容,频率升高后,二极管的单向导电性将会被破坏
___
### 二极管的等效电路

要分析二极管所在的电路,二极管相当于一个电阻,但是它是非线性的,对此我们需要给出它的等效电路来让我们能够简便地求解

```tikz
\usepackage{circuitikz}
\begin{document}
\begin{circuitikz}[american]

	\draw (5,0) node[below]{$u$};
	\draw (-0.2,0) node[below]{$O$};
	\draw[domain=0:5] plot (\x,{0.05*(exp(\x)-1)});
	\draw[domain=-3:0] plot (\x,{-0.05*(exp(-\x)-1)});
\end{circuitikz}
\end{document}
```
